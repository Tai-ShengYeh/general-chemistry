# 緩衝液：先收支，再算比值

學習目標：能依剩餘莫耳比計算緩衝pH，理解容量與近似限制。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 緩衝，需要兩種互相配合的型態

弱酸和足量的共軛鹼，可以抵抗少量外加酸鹼造成的pH變化。共軛鹼接住外來質子，弱酸消耗外來氫氧根。容量有限，不能說加多少都不變。

## 2. 加酸時，先做莫耳數收支

加入少量強酸時，先讓氫離子和共軛鹼反應。共軛鹼減少，弱酸增加。完成莫耳收支後，才把剩餘比值代入緩衝近似式。

## 3. 共軛鹼是弱酸兩倍，pH多少

醋酸的pKa取四點七六，共軛鹼零點二零莫耳，弱酸零點一零莫耳，兩者在同一溶液中。符合緩衝近似時，pH多少？

## 4. 答案：5.06

共軛鹼除弱酸是二，對數約零點三零。四點七六加零點三零，得到五點零六。共軛鹼較多，pH高於pKa，方向也合理。

## 5. 同樣pH，容量可以不同

酸鹼比例相同，近似pH相近。總量比較大的緩衝液，能消耗更多外加酸鹼。適度稀釋可能讓比值不變，但容量下降；極度稀釋時近似本身也可能失效。

## 6. 等量緩衝液加入0.010 mol酸

起初弱酸與共軛鹼各零點一零零莫耳。加零點零一零莫耳強酸，尚未耗盡。兩型各剩多少？再估pH。

## 7. 先反應，才代剩餘比值

弱酸增加到零點一一零莫耳，共軛鹼減少到零點零九零莫耳。四點七六加零點零九除零點一一的對數，約四點六七。若共軛鹼耗盡，就要改用適合的新平衡模型。
