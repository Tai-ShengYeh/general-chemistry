# 稀釋守恆與水合物配液

學習目標：能使用稀釋守恆，並以正確水合物莫耳質量計算配液。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 稀釋時，什麼不變

只加溶劑，沒有反應、損失或沉澱時，溶質莫耳數不變。前後都是濃度乘體積，所以得到稀釋公式。體積要用同一單位。

## 2. 先量原液，再定容

先算需要取多少原液。把這份原液轉到適當容量器具，再加溶劑到最後總體積。原液體積與最終體積是兩個不同的量。

## 3. 1.00 M配成0.100 M

要用一點零零莫耳濃度原液，配成兩百五十點零毫升、零點一零零莫耳濃度溶液，需要取多少原液？

參考答案：25.0 mL。

## 4. 答案：移取25.0 mL

移取二十五點零毫升原液，再定容到兩百五十點零毫升。不是再加兩百五十毫升水。檢查稀釋十倍，原液體積就是最後體積的十分之一。

## 5. 用五水硫酸銅，要把水算進質量

配一百點零毫升、零點一零零莫耳濃度硫酸銅，先算需要零點零一零零莫耳。若試劑是五水合物，每莫耳約兩百四十九點六八公克，應秤約二點五零公克。

## 6. 錯用無水物莫耳質量，濃度偏哪邊

拿的是五水硫酸銅，卻按無水硫酸銅莫耳質量一百五十九點六一，算出只需約一點六零公克。最後配出的濃度偏高還是偏低？

參考答案：偏低，約0.0639 M。

## 7. 答案：少秤，所以濃度偏低

一點五九六一公克五水合物，除兩百四十九點六八，再除零點一公升，約零點零六三九莫耳濃度。先讀試劑化學式與純度，才能把配液算對。
