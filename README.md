# 普通化學（一）　General Chemistry I

食品營養系大一・一學期・全套離線 HTML 投影片

**線上瀏覽：** https://tai-shengyeh.github.io/general-chemistry/

---

## 這是什麼

一套為**食品營養系**設計的普通化學教材。每一週從一個食品營養的問題出發，
用化學回答它，最後回到那個問題——化學是**詮釋食品現象的透鏡**，不是講完之後才貼上的應用。

每個檔案都是**單一 HTML**，離線可用：下載後直接用瀏覽器開啟，或 `Ctrl+P` 印成講義。
不需要安裝任何東西，沒有外部相依。

## 每一週的結構

- **開場錨點**：一個具體的食品營養問題（例如「食品法規為什麼以 pH 4.6 分界？」）
- **PART 1–5**：概念、例題、圖解
- **隨堂快問**：每個 PART 結尾三題——①迷思診斷 ②概念辨析 ③開放產出
- **錨點回收**：用本週的化學回答開場的問題，並說明「這個情境幫你理解了哪個概念」
- **重點總結・名詞對照・課後練習**

投影片的解答預設是**收合**的：按一次 `→` 展開解答，再按一次才翻頁；
列印時解答一律印出。

## 給教師的說明

- 題庫、課後精熟測驗的題目與解答、教師卷、平台匯入檔**不在本 repo**——
  它們留在本機，因為一旦公開，那些測驗就失去診斷價值。
- 投影片裡出現的**法規數值**（pH 4.6、121 °C、添加物限量、ADI、DRIs 等）
  會隨公告版本改變，**教學前請以主管機關現行公告為準**。
  化學機制不因數值調整而改變，但判定要以法規為準。
