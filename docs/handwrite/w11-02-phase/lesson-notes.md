# 相變熱量與食品結構

學習目標：能分段計算相變熱量，區分純物質相變與食品結構變化。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 加熱，不保證一直升溫

純物質在固定壓力的相變平台上，加入能量主要用於相變，溫度可維持不變。平台前後升溫用比熱，相變本身則用熔化或汽化焓。

## 2. 先分段，再加總

加熱曲線的斜段代表同一相升溫，水平段代表兩相共存的相變。這是理想純物質示意。食品通常是混合物，可能出現較寬的相變區間。

## 3. 冰在0度融化，需要多少熱

題設十八點零公克純冰，在一個大氣壓、零度全部融成零度水。熔化焓每莫耳六點零一千焦耳，莫耳質量十八點零二。需要多少熱？

參考答案：約6.00 kJ。

## 4. 答案：約6.00 kJ

十八點零公克除十八點零二，再乘六點零一，約六點零零千焦耳。溫度雖然沒有變，能量仍增加。若之後繼續把液態水加熱，才另外加上比熱那一段。

## 5. 巧克力起霜與蛋白凝固，不能混稱

脂肪多晶型與遷移會影響巧克力外觀；糖霜還可能來自水分與糖再結晶。蛋白質受熱變性聚集，涉及分子結構與交互作用，不能直接當成純物質的普通熔融相變。

## 6. 外壓降低，沸點怎麼變

液體沸騰的條件，是蒸氣壓等於外壓。若外壓降低，同一液體需要較高還是較低的溫度才能沸騰？

作答停頓：HTML 自動暫停；MP4 保留固定思考時間。

參考答案：較低溫度。

## 7. 答案：外壓低，沸點降低

較低溫度時，蒸氣壓就可以等於較低外壓，所以沸點下降。不同壓力下的沸點不能直接比較。讀相變圖，要同時說明物質、組成與壓力。
