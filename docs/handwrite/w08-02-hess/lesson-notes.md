# Hess定律與食品熱量

學習目標：能操作Hess加總與反寫，區分食品可代謝能與燃燒能。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 焓變，跟起終點有關

同樣的起點與終點，不管分幾步反應，總焓變相同。加總反應式時，中間物可以消去，對應焓變也要一起相加。這是Hess定律。

## 2. 走兩段，也算同一段總差

這裡用教學假設數值。甲到乙放出一百千焦耳，乙到丙吸收三十千焦耳。把兩步相加，乙消去，甲到丙的總焓變是負七十千焦耳。

## 3. 把反應反過來，數字怎麼變

剛才甲到丙的焓變是負七十千焦耳。若反過來走丙到甲，而且所有物質量也加倍，焓變是多少？

參考答案：＋140 kJ。

## 4. 先反號，再乘二

反過來時，負七十變正七十；再把反應物與產物都乘二，焓變也乘二，成為正一百四十千焦耳。反應條件與物理狀態也必須一致，才能相加。

## 5. 食品大卡，不只看燃燒熱

一大卡是一千小卡，精確等於四點一八四千焦耳。食品常用營養素能量因子估算可代謝能；彈卡計量得的是燃燒能，兩者概念不同。九、四、四只是常見概略因子。

## 6. 8.0 g脂肪，用9估算

題設只用脂肪能量因子，每公克九大卡。八點零公克脂肪提供約多少大卡？能不能把它當成整份食品的實測熱量？

參考答案：約72 kcal；不是整份食品實測總熱量。

## 7. 答案：此部分約72大卡

八乘九，約七十二大卡，只是本題脂肪部分的估算。整份食品還要考慮其他供能成分、採用因子與標示規則。會算乘法，也要能說出計算回答了什麼問題。
