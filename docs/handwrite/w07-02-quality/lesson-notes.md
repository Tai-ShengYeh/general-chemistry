# 酸價、過氧化價與可信結果

學習目標：能計算空白校正酸價，解釋PV限制及精密與準確的差異。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 先問方法量的是什麼

酸價主要反映可中和的游離脂肪酸，以每公克油所需的氫氧化鉀毫克數表示。過氧化價則主要量初級氧化產物。它們看的是不同現象，不能用一個取代另一個。

## 2. 同一瓶油，用不同方法看

油脂水解釋出游離脂肪酸，脂質氧化生成氫過氧化物，後者還會繼續分解。取樣、空白與方法條件也會影響數字。把化學變化和量測方法對起來。

## 3. 酸價題：先扣空白

油二點零零公克，樣品滴定量一點五零毫升，空白零點一零毫升。氫氧化鉀濃度零點一零零零莫耳每公升，莫耳質量五十六點一一。酸價是多少？

參考答案：3.93 mg KOH/g。

## 4. 答案：3.93 mg KOH/g

先扣空白，得到一點四零毫升。毫升乘莫耳每公升，再乘每莫耳五十六點一一公克，數值剛好可表示氫氧化鉀毫克數。最後除二公克油，得到三點九三。

## 5. PV低，有兩種可能

油剛開始氧化時，過氧化物可能很少。氧化進展後，過氧化物也可能分解成其他產物，讓PV再次下降。所以單獨一個低PV，不能證明油一定新鮮。

## 6. 哪一個結果更值得相信

同一樣品做兩次，數字很接近，但標準品回收率偏低。能不能因為重複結果漂亮，就直接認為結果正確？

## 7. 精密，不代表沒有系統偏差

兩次都量得很接近，表示重複性不錯。若標準品回收偏低，仍要查標準液、萃取損失、空白或方法干擾。定量分析要把樣品、方法與校核資料一起看。
