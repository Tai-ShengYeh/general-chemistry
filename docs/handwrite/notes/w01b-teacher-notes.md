## 與原教材不同、需要交代的地方

1. **苯甲酸 ADI 的來源與版本。** 原例 8–9 使用 5 mg/kg 體重/天，未在該題交代機構與年份。動畫保留 5 作為「原題給定標準」，沒有宣稱它是目前各機構一致的通用值。另新增 JECFA 2021 的群組 ADI 0–20 mg/kg 體重，按苯甲酸當量表示；WHO 資料庫明列先前 0–5 群組 ADI 已撤回。這不代表可把所有機構、所有用途的數值一律換成 20。

   - [WHO/JECFA 苯甲酸類資料庫](https://apps.who.int/food-additives-contaminants-jecfa-database/Home/Chemical/1227)
   - 相同 300 mg、60 kg：除以 5 為 100%；除以 20 為 25%。
   - 1 qt 題保留未捨入值 590.5536 mg：除以 5 為 196.8512%；除以 20 為 49.2128%。

2. **阿斯巴甜。** 例 6–7 的計算採 ADI 上限 40 mg/kg 體重/天。JECFA 2023 重申 0–40 的既有 ADI。此處說明比較基準，不由單一食品的比值推定個人風險。

   - [WHO/JECFA 阿斯巴甜資料庫](https://apps.who.int/food-additives-contaminants-jecfa-database/Home/Chemical/1850)

3. **「達到」與「超過」要分清楚。** 2400÷180 = 13.333… 罐；1000÷180 = 5.555… 罐。若只能數完整罐，分別是第 14 罐與第 6 罐超過題設 ADI 等量，不能把「約 13 罐」說成精確跨越點。反算是等量表達，不是建議份量；尚未計入其他來源。

4. **法規與營養數值採題設。** 600 mg/kg、QAC 的 0.1、肉品殘留 10/40 ppb、鈣/鐵/維生素 C 及鈉的各項基準均標為原題假設。沒有核實其對特定地區、食品類別、年齡性別族群在使用當日的全部適用性，故不以動畫代替現行公告或個別醫療判斷。ADI 與食品中的限量也不是同一種量。

5. **單位與有效數字。** 原換算表的 453.59 g、28.35 g、29.57 mL、236.6 mL、946.4 mL 為課堂近似值，動畫以近似符號表示。1 lb 的精確定義為 453.59237 g；1 in = 2.54 cm 為精確定義。500÷0.92 的計算值約 543.478 mL；若按密度兩位有效數字報告，為 5.4×10² mL。原題未充分交代 150、250、500 等尾端零的測量精度時，不替它們指定唯一精度。

   - [NIST SI 換算因子與精確關係](https://www.nist.gov/pml/special-publication-811/nist-guide-si-appendix-b-conversion-factors)

6. **營養的兩個分母。** 超過 RDA/AI 不等於已超過 UL；低於 UL 也不是個人零風險保證。維生素 C 兩顆合計 2000 mg，是恰等於題設 UL，若還有食物來源，總量需另加；不能只看補充劑就判斷全天攝取。

7. **長期平均與單次攝取。** ADI 不是急性中毒分界，也不是建議達到的攝入目標。多食品、多日的總暴露不能用一份食品的計算取代。

## 關鍵詞

| 符號 | 中文與意義 |
|---|---|
| density，ρ | 密度，質量與體積的比值 |
| dimensional analysis | 因次分析，安排換算因子使單位相消 |
| ADI | 每日可接受攝取量，用於長期暴露評估 |
| NOAEL | 無可見不良作用劑量；健康指引推導的一種出發點 |
| EAR | 估計平均需要量 |
| RDA | 建議攝取量 |
| AI | 足夠攝取量 |
| UL | 上限攝取量 |
| ppb | 十億分之一；本課為質量比 μg/kg |

## 操作與製作

開啟 `index.html` 選章；每章的完整資料夾要與首頁一起保留。播放器可暫停、跳幕、拖曳時間軸與調速，題目結束前會自動停下，按「繼續」才開始後面的解題。

`*.lesson.json` 是可編輯教材，`build_course.py` 使用本次建立的 handwrite-teaching skill 製作。`--narrate` 使用免金鑰的 edge-tts 台灣女聲，會連線產生音檔；已存在的相同文字音檔可沿用。字幕與旁白的句段對應仍為字數比例估算，未做逐字強制對齊。
