# 溶解、溫度與氣體壓力

學習目標：能分辨溶解速度和平衡溶解度，使用固定定義的Henry關係。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 溶解，要比較多種作用

溶質彼此與溶劑彼此要分開，再形成新的溶質溶劑作用。整體是否容易溶解，也要考慮熵與自由能，不能只看會不會放熱。相似者相溶是趨勢，不是絕對定律。

## 2. 離子溶解，水的方向有意義

水的氧端偏負，通常朝向陽離子；氫端偏正，朝向陰離子。這些水合交互作用有助穩定分散的離子。離子化合物並不是每一種都容易溶於水。

## 4. 趨勢要回到指定物質

不是所有固體升溫都增加溶解度。要看特定物質的溶解度曲線與相態。也要分清溶解速度和最後能溶多少，攪拌讓溶解較快，不必然提高平衡溶解度。

## 5. 氣體濃度，看上方分壓

在適用的稀溶液與固定溫度下，Henry定律可寫成溶解濃度等於常數乘氣體分壓。要註明常數採用的定義。開瓶讓二氧化碳分壓下降，飲料中的氣體便會逐漸逸出。

## 7. 答案：終值減半，時間另算
