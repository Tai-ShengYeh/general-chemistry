# 普通化學手寫動畫

解壓整個資料夾後開啟 `index.html`，選擇主題與章節，再按播放。

遇到題目會自動暫停。先自己計算或說出理由，再按「繼續」看解答。可以拖曳時間軸、調速、上一幕、下一幕或重新開始。手機可橫放看清完整算式。

播放器需和相同資料夾的index.html、assets一起保留，不要只搬player.html。若瀏覽器限制本機音訊，可在本資料夾執行 `python -m http.server 8000`，再開啟 `http://localhost:8000/`。

配音已隨教材附上，播放不需要連線配音服務。回原課程、原投影片與線上因次分析練習的連結需要網路。這份教材是可操作的HTML動畫，沒有另外製作MP4。

可編輯各章 `.lesson.json`。重建時使用本工作區的handwrite-teaching技能，以及build_course.py；正式旁白以台灣女聲、無配樂製作。重新配音需要連線，但已完成的音檔會快取。

教師備註說明近似、來源與題目答案。W01b舊教材保留原六章，其餘每個主題兩章。主題名稱依原網站W01–W16及兩個延伸專題，不把考試週另外生成教學內容。
