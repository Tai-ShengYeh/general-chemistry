# 油脂鏈鎖氧化與褐變

學習目標：能把油脂氧化和褐變對策對應機制，分清外觀與安全。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 一個自由基，可能延續很多次反應

脂質自動氧化可用起始、傳遞與終止的鏈鎖模型理解。光、熱與微量金屬等條件會影響反應。脂質氧化不只一種途徑，這裡聚焦自由基鏈鎖。

## 2. 對策，要對到鏈鎖的位置

避光可減少部分光起始，減氧限制氧參與，適當螯合能影響金屬催化；鏈鎖終止型抗氧化劑則捐出氫，讓自由基轉成較不易延續鏈鎖的型態。效果依配方而變。

## 3. 換遮光瓶，主要改哪一環

同配方、同溫度下，透明包裝換成合適遮光包裝。這主要是在降低光起始，還是把所有既有油耗味分子還原回新鮮油？

## 4. 答案：延緩新損傷，不是倒帶

遮光主要限制光參與的新反應，不能保證把已生成的醛、酮等裂解產物消除。抗氧化處理也是延緩工具，不能把已劣變的油當成恢復新鮮。

## 5. 褐變，先分是否需要酵素

切開蘋果的酵素性褐變，與多酚、氧及酵素活性有關。梅納反應通常需要還原糖與可反應胺基，不需要酵素；焦糖化則是糖受熱的反應，不必有胺基。

## 6. 檸檬水為什麼可能減少蘋果褐變

檸檬水可能降低pH，並帶入還原性成分。這些作用分別可以影響酵素活性與醌的累積。能不能把褐變變慢直接當成食物已消毒？

參考答案：不能；褐變變慢不等於完成消毒。

## 7. 把可見現象，連回正確機制

酸度與還原作用可能減緩某些褐變，但不能只看顏色判定衛生安全。不同抗氧化手段針對不同位置，效果還需實測。完成本課後，請用機制、條件與證據，解釋食品現象。
