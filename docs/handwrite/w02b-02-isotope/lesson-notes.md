# 同位素比值與混合模型

學習目標：能雙向換算δ與比值，並交代兩端混合模型的限制。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 負的δ，不是負的同位素量

同位素比值用樣品與標準的比值比較。δ為負，只代表樣品的比值比標準低，不代表同位素的數量是負數。千分比與百分比也不能混用。

## 2. 把標準當成比較基準

標準的比值設為一倍。若樣品是零點九七五倍，差值是負零點零二五，換成千分比就是負二十五。這是相對偏差，不是樣品有百分之二點五的碳十三。

## 3. δ等於負11，R是多少倍

δ等於負十一千分比。樣品比值是標準的多少倍？把公式反過來，不要忘記先除以一千。

作答停頓：HTML 自動暫停；MP4 保留固定思考時間。

參考答案：0.989倍。

## 4. 答案：0.989倍

一減零點零一一，是零點九八九。比值依然是正數，只是比標準低。若直接用負十一去乘標準，會得到不合理的負比值。

## 5. 兩端混合，先寫假設

教學簡化模型假設兩個來源的碳貢獻可比較，以碳來源分率線性混合δ。真實判定還要考慮基質、內標、方法與不確定度，不能直接把這個分率當成整瓶糖的質量百分比。

## 6. 混合值負22，反推f

在剛才的兩端模型中，真樣負二十五，另一來源負十。量得混合值負二十二，請反算來源分率。這裡只做模型計算，不做法規合格判定。

作答停頓：HTML 自動暫停；MP4 保留固定思考時間。

參考答案：f＝0.20。

## 7. 答案：20%，但要交代它是什麼

負二十二減負二十五，差三；再除十五，得到零點二。這是指定混合模型下的碳來源分率。要判斷是否摻假，仍要使用經驗證的方法與適用的判定規則。
