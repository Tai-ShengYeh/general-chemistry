# 加權平均與化學式計算

學習目標：能反算同位素豐度與元素質量分率，正確處理結晶水。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 先檢查模型，再代數字

計算題先把粒子的身分寫清楚。單原子磷三負離子，和磷酸根不同。磷酸根有四個氧，整體帶負三；不能把它當作單原子磷三負離子。

## 2. 反推豐度，用 x 和1減x

若假設只有兩種同位素，兩個豐度分率的和為一。設第一種為未知數，另一種就是一減未知數。這是加權平均反算，不是把兩個質量直接平均。

## 3. 反推銅的豐度

給定兩個同位素質量六十二點九三零與六十四點九二八，平均六十三點五五。哪一種較多？請先估方向，再解方程。

## 4. 平均值靠近誰，誰的權重較大

整理方程後，一點九九八乘未知數等於一點三七八。所以較輕同位素的豐度約百分之六十九。答案在零到一之間，也符合平均值較接近較輕同位素。

## 5. 含結晶水，也要算進總質量

乳酸鈣五水合物包含五個結晶水。若秤取這個水合物，分母要包含水的質量。鈣的個數沒有增加，但整個化合物變重，所以鈣的質量分率較低。

## 6. 要500 mg元素鈣，反推化合物量

這是一道數學反算題。若碳酸鈣中鈣的質量分率取零點四零零，要提供五百毫克元素鈣，需要多少碳酸鈣？

## 7. 反算要除以分率

五百除零點四，得到一千兩百五十毫克碳酸鈣。代回檢查，一千兩百五十乘零點四，確實是五百毫克鈣。計算的是化合物當量，實際使用還要看標示與個別需求。
