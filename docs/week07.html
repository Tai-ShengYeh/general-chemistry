PART 6.1

電磁輻射

Electromagnetic Radiation
波的性質・c = λν・電磁波譜・連續光譜與線光譜

波的性質 Properties of Waves

定義波長 (wavelength, λ):相鄰兩波峰間的距離(m、nm)。
頻率 (frequency, ν):每秒通過定點的波數(s−1 = Hz)。
振幅 (amplitude):波的高度,決定光的強度(亮度)。
  • 電磁波 (electromagnetic radiation):電場與磁場交互振盪、在真空中傳播的波
  • 電磁波不需介質,真空中皆以光速行進

波長與頻率的關係 c = λν

c = λ × ν  ,  c = 2.998 × 108 m/s(真空中光速)
  • λ 與 ν 成反比:波長越長,頻率越低
  • 單位務必統一:λ 常以 nm 給出,計算時換成 m(1 nm = 10−9 m)
長波長 λ ↑
低頻率、低能量
⟷
短波長 λ ↓
高頻率、高能量

例題 1:波長與頻率換算 Example 1

例題鈉燈發出的黃光波長為 589 nm,求其頻率。
解:
先換單位:λ = 589 nm × (10−9 m / 1 nm) = 5.89 × 10−7 m
ν = c / λ = (2.998 × 108 m/s) ÷ (5.89 × 10−7 m)
  = 5.09 × 1014 s−1(3 位有效數字)
檢查:可見光頻率約 1014–1015 Hz,數量級合理 ✓

PART 6.2

量子化與光子

Quantization and Photons
黑體輻射・Planck 假說 E = hν・光電效應・波粒二象性

黑體輻射之謎 Blackbody Radiation

  • 加熱固體會發光:溫度升高,顏色由紅 → 橙 → 白 → 藍白
  • 古典物理預測:短波長處輻射強度應無限增大 —「紫外災變 (ultraviolet catastrophe)」
  • 實驗事實:強度在某波長達最大值後下降,古典理論完全失敗
轉捩點1900 年 Planck 提出革命性假設,成功解釋黑體輻射曲線 — 量子論從此誕生。

Planck 量子假說 Planck's Quantum Hypothesis

假說能量的吸收與放出不是連續的,而是一份一份的最小單位 —量子 (quantum)。每一份的能量與頻率成正比:
E = hν  ,  h = 6.626 × 10−34 J·s(Planck 常數)
  • 能量「量子化 (quantized)」:如階梯只能站在特定高度,不像斜坡可連續變化
  • h 極小 → 日常世界感覺不到能量的顆粒性,但在原子尺度極為重要

例題 2:光子能量 Example 2

例題承例題 1,鈉黃光 (λ = 589 nm, ν = 5.09 × 1014 s−1):
(a) 一個光子的能量?(b) 1 mol 光子的總能量?
解:
(a) E = hν = (6.626 × 10−34 J·s)(5.09 × 1014 s−1)
    = 3.37 × 10−19 J(單一光子,極小)
(b) Emol = 3.37 × 10−19 J × 6.022 × 1023 /mol
    = 2.03 × 105 J/mol = 203 kJ/mol — 與化學鍵能同數量級,這正是光能引發化學反應的原因!

光電效應 The Photoelectric Effect

現象光照射金屬表面,可將電子打出(光電子)。
  • 存在閾頻率 (threshold frequency):光頻率低於它,再強的光也打不出電子
  • 頻率夠高時:光越強 → 電子數目越多;頻率越高 → 電子動能越大
  • 古典波動說無法解釋:若光是連續的波,能量累積夠久應該總能打出電子

Einstein 的光子說 Einstein's Photon Theory (1905)

解釋光由粒子狀的能量包 —光子 (photon)— 組成,每個光子能量 E = hν。一個光子撞出一個電子,「一對一」交易。
KE電子 = hν − W  (W:功函數,束縛能)
  • hν < W:單一光子能量不足 → 無論光多強都打不出電子
  • hν > W:多餘能量成為電子的動能
重點光同時具有波動性(繞射、干涉)與粒子性(光電效應)—波粒二象性的第一個實例。

例題 3:光電效應計算 Example 3

例題某金屬的功函數 W = 3.43 × 10−19 J。以波長 450 nm 的藍光照射,能否打出電子?若能,電子的最大動能為何?
解:
光子能量:E = hc/λ = (6.626 × 10−34)(2.998 × 108) ÷ (4.50 × 10−7)
  = 4.41 × 10−19 J
比較:4.41 × 10−19 J > W = 3.43 × 10−19 J → 可以打出電子
KE = hν − W = 4.41 × 10−19 − 3.43 × 10−19 = 9.8 × 10−20 J(2 位有效數字,由減法的小數位決定)

波粒二象性 Wave–Particle Duality

光的波動性證據

  • 繞射 (diffraction)
  • 干涉 (interference)
  • c = λν 的波動描述

光的粒子性證據

  • 黑體輻射(能量量子化)
  • 光電效應(光子一對一撞擊)
  • E = hν 的粒子描述
重點「光是波還是粒子?」— 都是。用哪種圖像取決於觀察的實驗;稍後會看到,電子也一樣。

隨堂快問 ②:量子化與光電效應 Quick Check 2

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1光電效應中,增加光的強度(但不改變頻率),會使?
A 光電子動能變大B 光電子數目變多C 低於低限頻率也能打出電子D 完全沒有影響
2若入射光頻率低於金屬的低限頻率,再怎麼增加強度也打不出電子。這說明?
A 光是連續的波B 光的能量以光子為單位一份一份給C 電子質量太大D 金屬表面太光滑
3為什麼光電效應無法用古典波動說解釋?請指出波動說預測了什麼、實驗卻看到什麼。
解答:
1. B — 強度 = 光子數目;動能只由頻率決定。選 A 是最典型的迷思:把「光比較亮」當成「能量比較大」。一個電子只吸收一個光子,所以決定它能不能跑、跑多快的是單顆光子的能量 hν,與有幾顆無關。
2. B — 有低限頻率,正是能量量子化的證據。若光是連續的波,累積足夠時間就該打出電子 —— 但實驗上不論等多久都不會。這一點直接逼出了光子概念。
3. 波動說預測「累積」,實驗卻看到「瞬時且有門檻」 — 波動說預測:能量隨強度與時間累積,任何頻率只要夠亮或夠久都能打出電子,且動能隨強度增加。
實驗看到:低於低限頻率完全打不出;超過就立即放出;動能只隨頻率增加。這題要練的是「一個理論被推翻」的標準論證形式:指出預測與觀測的具體衝突,而不是只說「古典理論不夠好」。
PART 6.2–6.3

氫原子光譜與 Bohr 模型

Hydrogen Spectrum and the Bohr Model
線光譜・Balmer 系列・能階與躍遷・模型的成敗

氫原子線光譜 Hydrogen Line Spectrum

  • 氫氣放電管發光,經稜鏡分光後,可見區只有四條亮線:

656 nm 紅486 nm 藍綠434 nm 藍紫410 nm 紫

  • 1885 年 Balmer 發現這些波長符合簡單的整數規律 —Balmer 系列
  • 紫外區另有 Lyman 系列、紅外區有 Paschen 系列
待解之謎為何是「整數」規律?整數暗示了某種量子化 — Bohr 在 1913 年給出答案。

Rydberg 公式 The Rydberg Formula

1/λ = R∞ (1/n₁² − 1/n₂²)  ,  n₂ > n₁
  • R∞ = 1.097 × 107 m−1(Rydberg 常數),n₁、n₂ 為正整數
  • Balmer 系列(可見光):n₁ = 2;Lyman 系列(UV):n₁ = 1;Paschen 系列(IR):n₁ = 3
  • 這是經驗公式 — 先有規律,後來才由 Bohr 模型賦予物理意義

Bohr 模型的假設 The Bohr Model (1913)

  1. 電子只能在特定半徑的定態軌道 (stationary orbit) 上繞核運行,每條軌道對應一個量子數 n = 1, 2, 3, …
  2. 電子在定態軌道上不放出能量(違反古典電磁學,但符合實驗)
  3. 電子在兩軌道間躍遷 (transition) 時,吸收或放出一個光子,其能量恰等於兩能階差:|ΔE| = hν
定義基態 (ground state):n = 1,能量最低。
激發態 (excited state):n ≥ 2 的較高能階。

氫原子的能階 Energy Levels of Hydrogen

En = −2.18 × 10−18 J × (1/n²)  ,  n = 1, 2, 3, …
  • 能量為負值:以「電子離核無窮遠 (n = ∞)」為零點,束縛態能量低於零
  • n = 1:E₁ = −2.18 × 10−18 J(最穩定);n 越大能量越高、間距越密
  • n → ∞,E → 0:電子脫離原子 →游離 (ionization)
重點能階像階梯:電子只能「站在階上」,不能停在兩階之間 — 這就是線光譜的由來。

躍遷:吸收與放光 Transitions: Absorption & Emission

低能階 n低
↑ 吸收光子 (ΔE > 0)
高能階 n高
吸收光譜:暗線
高能階 n高
↓ 放出光子 (ΔE < 0)
低能階 n低
發射光譜:亮線
ΔE = E末 − E初 = −2.18 × 10−18 J (1/n末² − 1/n初²)

光子能量 = |ΔE|;躍遷距離越大,放出的光子能量越高、波長越短。

例題 4:躍遷波長計算 Example 4

例題氫原子中電子由 n = 3 躍遷至 n = 2,求放出光子的波長,並指出其顏色。
解:
ΔE = −2.18 × 10−18 (1/2² − 1/3²) = −2.18 × 10−18 (1/4 − 1/9)
  = −2.18 × 10−18 × 0.1389 = −3.03 × 10−19 J(負 → 放出光子)
光子能量 E = |ΔE| = 3.03 × 10−19 J
λ = hc/E = (6.626 × 10−34)(2.998 × 108) ÷ (3.03 × 10−19)
  = 6.56 × 10−7 m = 656 nm(紅光)— 正是 Balmer 系列的紅線!

Bohr 模型的成功與限制 Successes and Limitations

成功之處

  • 完美解釋氫原子線光譜
  • 導出 Rydberg 常數的理論值
  • 引入能階、量子數、基態/激發態等核心概念

限制

  • 只適用於單電子系統(H、He+、Li2+)
  • 無法解釋多電子原子光譜與譜線細部結構
  • 「固定軌道」的圖像違反測不準原理(後述)
承先啟後Bohr 模型是通往量子力學的重要跳板 —「能階」概念被保留,「軌道」則被「軌域」取代。

隨堂快問 ③:氫原子光譜與 Bohr 模型 Quick Check 3

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1氫原子中,電子由 n = 3 躍遷到 n = 2 時會?
A 吸收光子B 放出光子C 不涉及光子D 放出電子
2下列哪一個躍遷放出的光子能量最大?
A n = 2 → 1B n = 3 → 2C n = 4 → 3D n = 5 → 4
3Bohr 模型成功解釋了氫原子光譜,卻無法解釋氦原子。這說明模型的什麼限制?
解答:
1. B(放出光子) — 由高能階掉到低能階 → 放出能量差對應的光子。口訣:往上吸、往下放。判斷時先看 n 是變大還是變小,不要背哪個系列。
2. A(n = 2 → 1) — 能階間距隨 n 增大而急遽變窄,所以最靠近核的那一階落差最大。選 D 的同學以為「跨越的 n 差一樣就能量一樣」。能階不是等間距 —— En ∝ −1/n2,n 越大越擠。畫一次能階圖就不會再錯。
3. 它只適用於單電子系統 — Bohr 模型沒有處理電子之間的排斥,一旦有第二個電子(氦)就失效。這是模型的邊界:能算對一個案例不代表理論正確。真正解決要等量子力學的波函數描述 —— 而那也是為什麼下一節要換模型。
PART 6.3

物質波與量子力學模型

Matter Waves and the Quantum-Mechanical Model
de Broglie 物質波・測不準原理・波函數 ψ 與軌域

de Broglie 物質波 de Broglie's Matter Waves (1924)

假說光既有粒子性,則粒子(如電子)也應有波動性。任何運動中的粒子都伴隨一個波長:
λ = h / (mv)  (m:質量 kg,v:速率 m/s)
  • 1927 年電子繞射實驗證實:電子束通過晶體產生繞射圖樣,波動性成立
  • 應用:電子顯微鏡 — 電子波長遠短於可見光,解析度更高

例題 5:de Broglie 波長 Example 5

例題(a) 電子 (m = 9.109 × 10−31 kg) 以 5.97 × 106 m/s 運動,求其波長。
(b) 質量 0.145 kg 的棒球以 40.0 m/s 飛行,波長又是多少?
解:
(a) λ = h/(mv) = 6.626 × 10−34 ÷ [(9.109 × 10−31)(5.97 × 106)]
    = 1.22 × 10−10 m = 0.122 nm — 與原子尺度相當,波動性顯著!
(b) λ = 6.626 × 10−34 ÷ [(0.145)(40.0)] = 1.14 × 10−34 m
遠小於任何可測尺度 → 巨觀物體的波動性完全觀察不到。

Heisenberg 測不準原理 Heisenberg Uncertainty Principle

原理無法同時精確得知一個粒子的位置與動量:位置測得越準,動量(速度)就越不準,反之亦然。
Δx · Δ(mv) ≥ h / 4π
  • 這不是儀器不夠好,而是自然界的本質限制
  • 對電子這種輕粒子影響巨大 → Bohr「電子沿固定軌道運行」的說法不可能成立
  • 只能談電子「出現在某處的機率」— 通往量子力學模型

量子力學模型與波函數 ψ Quantum Mechanics & Wave Functions

定義1926 年 Schrödinger 以波動方程式描述電子,其解稱波函數 (wave function, ψ);ψ² 代表在空間各點找到電子的機率密度。
  • 每個 ψ 對應一組量子數與一個確定的能量 → 能量仍然量子化
  • 電子不再有「軌道路徑」,而是以「機率雲 (electron cloud)」描述
  • 此模型適用於所有原子,不限單電子系統

軌域:機率分布 Orbitals as Probability Distributions

定義軌域 (orbital):一個波函數 ψ 所描述的空間機率分布;慣例上畫出「電子出現機率 90% 的邊界曲面」。
軌道 orbit(Bohr)軌域 orbital(量子力學)

隨堂快問 ④:物質波與量子力學模型 Quick Check 4

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1de Broglie 波長 λ = h/mv。為什麼棒球的波動性觀察不到?
A 棒球不是粒子B 質量太大,λ 小到無法偵測C 速度太慢D 棒球不帶電
2測不準原理說的是?
A 儀器不夠精密B 位置與動量無法同時精確確定C 電子沒有位置D 測量一定有人為誤差
3量子力學說「軌域是機率分布」。這跟 Bohr 說的「電子在固定軌道上運行」有什麼根本不同?
解答:
1. B — h 極小(6.626×10−34),m 一大,λ 就小到遠低於任何可測尺度。所以波粒二象性對所有物體都成立,只是對巨觀物體完全觀察不到。不是「大東西沒有波動性」,是「小到測不出來」。
2. B — 這是自然的本質限制,不是儀器問題。選 A/D 是最常見的誤解 —— 以為換更好的儀器就能解決。測不準源自波粒二象性本身,再精密的儀器也繞不過。
3. 從「確定的路徑」變成「出現的機率」 — Bohr 認為電子有明確軌道(像行星);量子力學說只能給出「在某處出現的機率」,連「路徑」這個概念都不適用。這也是為什麼要改叫「軌域 orbital」而不是「軌道 orbit」—— 一字之差,是兩種世界觀。學生若還在腦中畫圓形軌道,後面的 s/p/d 形狀就無法理解。

主量子數 n Principal Quantum Number

定義主量子數 (principal quantum number, n):決定軌域的能量高低與平均離核距離(大小)。允許值:n = 1, 2, 3, …(正整數)。
  • n 相同的軌域合稱一個殼層 (shell):K、L、M、N…
  • n 越大 → 軌域越大、能量越高、電子離核越遠
  • 對氫原子,能量只由 n 決定(即 Bohr 的 En 公式)

角量子數 l Angular Momentum Quantum Number

定義角量子數 (l):決定軌域的形狀。允許值:l = 0, 1, 2, …, (n−1)。

記號spdf
形狀球形啞鈴形多為四葉形更複雜
  • 同一 n 內不同 l 的軌域組成次殼層 (subshell):如 n = 2 有 2s、2p 兩個次殼層
  • n = 1 只有 s;n = 2 有 s、p;n = 3 有 s、p、d

磁量子數與自旋量子數 ml and ms

定義磁量子數 (ml):決定軌域的空間方向。允許值:−l, …, 0, …, +l,共 (2l + 1) 個。
自旋量子數 (ms):描述電子自旋方向,只有 +½ 或 −½ 兩種。
  • l = 0 → ml = 0(1 個 s 軌域);l = 1 → ml = −1, 0, +1(3 個 p 軌域)
  • l = 2 → ml = −2, −1, 0, +1, +2(5 個 d 軌域)
  • ms 屬於電子而非軌域;一個軌域最多容納 2 個自旋相反的電子

例題下列 (n, l, ml, ms) 組合何者合法?不合法者指出原因。
(a) (2, 1, 0, +½)  (b) (2, 2, 0, −½)  (c) (3, 1, −2, +½)  (d) (1, 0, 0, −½)  (e) (3, 2, −1, 1)
解:
(a) 合法 — 2p 軌域中的電子
(b) 不合法 — l 最大只能到 n−1 = 1,l = 2 超出範圍
(c) 不合法 — l = 1 時 ml 只能是 −1, 0, +1
(d) 合法 — 1s 軌域中的電子
(e) 不合法 — ms 只能是 +½ 或 −½

s 軌域 s Orbitals (l = 0)

  • 形狀:球形對稱,各方向機率相同
  • 每個殼層都有一個 s 軌域:1s、2s、3s…
  • n 越大,球越大;2s 以上內部出現機率為零的節面 (node)
  • 節面數 = n − 1(對 s 軌域)

p 軌域 p Orbitals (l = 1)

  • 三者能量相同(簡併 degenerate),僅方向不同
  • 從 n = 2 開始出現(2p、3p、…)

回到本週的錨點 Anchor Answered

第 7 週開場問的是:胡蘿蔔為什麼是橙色?分光光度計為什麼能靠「顏色」測出濃度?

用這一週的化學回答

  • 我們看到的顏色是被吸收掉那個顏色的補色:β-胡蘿蔔素吸收藍紫光(約 450 nm),剩下透出來的就是橙色。
  • 吸收發生在電子躍遷:光子能量 E = hν 剛好等於兩個能階的差,才會被吸收。共軛雙鍵越長,能隙越小,吸收波長越長。
  • 分光光度計量的就是這件事:A = εbc(Beer–Lambert) —— 吸光度與濃度成正比。
  • 所以稀釋一半,吸光度也減半 —— 「顏色變淡」不只是感覺,它是可以量化的。
這個情境幫你理解的化學是顏色是能階量子化的肉眼證據。E = hν 不是抽象公式,你每天看到的每一個顏色都是它的結果 —— 也因此顏色可以拿來做定量分析。
