# pH計算與食品判讀

學習目標：能以指定條件計算pH與pOH，辨認食品pH界線的限制。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. pH是對數，不是線性刻度

pH嚴格定義使用氫離子活性。稀、近理想水溶液常用濃度近似。差一個pH單位，代表活性相差十倍；溫度與校正條件也要說明。

## 2. 酸與鹼，各走自己的那條路

已知氫離子濃度，求pH。已知氫氧根濃度，先求pOH，再用水的離子積連接。二十五度的入門近似，pH加pOH等於十四；別把十四當成任何溫度都固定。

## 3. 0.010 M鹽酸的pH

題設二十五度、稀溶液近似，鹽酸完全電離，忽略水自解離的相對貢獻。零點零一零莫耳濃度的pH是多少？

## 4. 答案：2.00

十的負二次方取負對數，得到二。濃度有兩位有效數字，pH保留兩位小數，報二點零零。若酸極稀，水自解離不可忽略，就不能直接把酸濃度當氫離子濃度。

## 5. 氫氧化鈉，先求pOH

二十五度，零點零零二五莫耳濃度氫氧化鈉完全電離。先算負對數得pOH二點六零，再用十四減去它，pH是十一點四零。鹼液算出酸性數值，就要檢查你算的是哪一個。

## 6. pH低於4.6，就保證能常溫保存嗎

食品課程常提到四點六這個界線。單靠量到低於四點六，能不能直接斷定任何自製食品都能常溫保存？請把化學量測與完整加工驗證分開。

參考答案：不能；單一pH不等於經驗證的安全製程。

## 7. 界線有用途，也有適用範圍

食品酸度分類要看適用法規與最終平衡pH。四點六不是所有危害消失的開關，也不能單靠它決定家庭加工程序。這裡練習量測與條件判讀，不提供罐藏加熱時程。
