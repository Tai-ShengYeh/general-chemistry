原子的組成與同位素

Atomic Structure and Isotopes
次原子粒子・原子序與質量數・同位素・平均原子量

次原子粒子的性質 Subatomic Particles

粒子符號位置電荷質量 (amu)
質子 protonp+原子核內+11.0073 ≈ 1
中子 neutronn0原子核內01.0087 ≈ 1
電子 electrone−核外−10.00055 ≈ 0
重點質量集中在原子核(質子+中子);化學性質則由核外電子決定。中性原子:電子數 = 質子數。

原子序、質量數與核種符號 Atomic Number & Mass Number

定義原子序 (atomic number) Z = 質子數,決定元素種類。
質量數 (mass number) A = 質子數 + 中子數。
AZX  例:126C、3517Cl、23892U
  • 中子數 = A − Z
  • Z 與元素符號 X 重複,常省略:寫成 12C 或「碳-12」
  • 離子:右上角標示電荷,如 24Mg2+

例題 2:核種符號 Example 2

例題寫出下列各粒子的質子數、中子數與電子數:
(a) 5626Fe  (b) 56Fe3+  (c) 32S2−(S 的原子序為 16)
解:
(a) 質子 = Z = 26;中子 = A − Z = 56 − 26 = 30;中性原子 → 電子 = 26
(b) 質子 26、中子 30 不變;失去 3 個電子 → 電子 = 26 − 3 = 23
(c) 質子 16;中子 = 32 − 16 = 16;得到 2 個電子 → 電子 = 16 + 2 = 18
注意形成離子時只有電子數改變,質子與中子數不變!

同位素 Isotopes

定義同位素 (isotopes):質子數相同(同一元素)、但中子數不同的原子,故質量數不同。
氫的同位素符號質子中子天然豐度
氕(氫)protium1H1099.99%
氘 deuterium2H (D)110.01%
氚 tritium3H (T)12微量(放射性)

同位素的化學性質幾乎相同(電子數相同),但質量與核性質不同。應用:碳-14 定年、醫學造影。

原子質量單位 Atomic Mass Unit (amu)

定義1 amu(又寫作 u 或 Da)= 一個 12C 原子質量的 1/12。
1 amu = 1.6605 × 10−24 g
  • 以 12C = 12 amu(精確值)為基準的相對質量標度
  • 質子、中子質量各約 1 amu,故原子質量 ≈ 質量數 A
  • 例:1H = 1.0078 amu、16O = 15.9949 amu(接近但不等於整數)

平均原子量 Average Atomic Mass

定義週期表上的原子量是各同位素質量依天然豐度 (natural abundance) 加權的平均值。
平均原子量 = Σ(同位素質量 × 豐度分率)
  • 豐度以小數表示:75.77% → 0.7577
  • 平均值必介於最輕與最重同位素質量之間,且靠近豐度最高者
  • 因此週期表的原子量幾乎都不是整數

例題 3:平均原子量計算 Example 3

例題氯有兩種穩定同位素:35Cl(34.969 amu,豐度 75.77%)與 37Cl(36.966 amu,豐度 24.23%)。求氯的平均原子量。
解:
平均原子量 = (34.969 amu)(0.7577) + (36.966 amu)(0.2423)
= 26.496 amu + 8.957 amu
= 35.45 amu(4 位有效數字)
檢查:35.45 介於 34.97 與 36.97 之間,且較靠近豐度高的 35Cl ✓

例題 4:由平均原子量反推豐度 Example 4

例題銅的平均原子量為 63.55 amu,由 63Cu(62.930 amu)與 65Cu(64.928 amu)組成。求兩同位素的豐度。
解:設 63Cu 豐度分率為 x,則 65Cu 為 (1 − x):
62.930x + 64.928(1 − x) = 63.55
64.928 − 1.998x = 63.55  →  1.998x = 1.378  →  x = 0.6897
63Cu ≈ 69.0%,65Cu ≈ 31.0%
檢查:平均值靠近 63Cu → 63Cu 豐度應較高 ✓
技巧兩種同位素時設 x 與 (1−x),一元一次方程式即可解。

隨堂快問 ①:同位素與平均原子量 Quick Check 1

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1下列何者互為同位素?
A 12C 與 14NB 35Cl 與 37ClC O2 與 O3D Na 與 Na+
2銅有 63Cu(69.2%)與 65Cu(30.8%)。平均原子量最接近?
A 63.0B 63.6C 64.0D 65.0
3氯的平均原子量是 35.45。有沒有任何一個氯原子的質量是 35.45 amu?為什麼?
解答:
1. B — 同位素 = 質子數相同、中子數不同。選 C 是同素異形體(同元素不同分子形式);選 D 是離子(電子數不同);選 A 連元素都不同。固定動作:先看質子數是否相同。
2. B(63.6) — 63×0.692 + 65×0.308 = 63.6。選 C(64.0)的同學取了算術平均,忽略豐度加權。加權平均一定偏向豐度大的那一邊 —— 63 的比例較高,所以答案必須小於 64。這個判斷不必計算就能排除 C、D。
3. 沒有 — 任何一個氯原子不是 35Cl(約 35 amu)就是 37Cl(約 37 amu),沒有 35.45 的個體。35.45 是整群原子的加權平均,是統計量不是個體屬性。把平均值誤當成個體性質是很常見的推理錯誤 —— 就像「平均每戶 2.3 人」不代表有 0.3 個人。
PART 2.2

同位素在食品檢測的應用

Isotopes in Food Authentication
δ 記號・蜂蜜的真假・產地溯源・有機與合成

同位素豐度不是固定的常數 Abundance Is Not a Constant

  • 上一段算平均原子量時,把同位素豐度當成固定值——那是為了計算方便的近似
  • 真實情況:同一種元素在不同來源裡,同位素比例會有微小但穩定的差異
  • 差異來自物理與生化過程對輕重同位素的偏好(質量差 → 反應速率差)
  • 這個「微小差異」小到不影響化學性質,卻大到可以當指紋
為什麼這對食品檢驗這麼有用一般的成分分析只能回答「裡面有什麼」;同位素比值可以回答「它從哪裡來」——而摻假、產地標示不實、有機認證造假,問的正是後面這個問題。

同位素比值怎麼表示:δ 記號 The Delta Notation

δ13C (‰) = [ (R樣品 / R標準) − 1 ] × 1000　　R = 13C / 12C
  • 差異在千分之幾的等級,所以用千分率 ‰,而且一定要對照國際標準品
  • δ 為負 = 樣品比標準品更缺乏重同位素(有機物多半如此)
  • 常用的四組:δ13C(碳源)、δ15N(氮源)、δ2H / δ18O(水源)
  • 儀器:同位素比值質譜儀(IRMS),量的不是「有多少」而是「比例是多少」
注意這與「有沒有輻射」無關這裡用的 13C、15N、2H 都是穩定同位素,不會衰變、沒有放射性。只有後面講到的 14C 是放射性的。

應用一:蜂蜜是不是摻了糖漿 Is This Honey Adulterated?

  • 植物固定 CO2 有兩條路徑,對 13C 的排斥程度不同
  • C3(多數蜜源植物、稻麥、大豆):δ13C −22 ~ −30‰
  • C4(甘蔗、玉米):δ13C −10 ~ −16‰
  • 摻入蔗糖漿或玉米糖漿 → 整體 δ13C 往上偏移
關鍵設計:自帶內部標準直接看蜂蜜的 δ13C 不夠——不同蜜源本來就有差異。
做法是把蜂蜜裡的蛋白質分離出來一起測:加進去的糖漿不含蛋白質,所以蛋白質的 δ13C 代表真蜜原本的值。
兩者的差距,就是摻假的量。
這是「內部標準」思維的漂亮示範找一個不會被造假動到的成分當基準,拿它去比對可能被動過的部分。同一個思路在第 7 週的一級標準品、第 10 週的檢量線都會再出現。

例題:算出摻了多少 C4 糖 Example: How Much C4 Sugar?

C4 糖 (%) = δ13C蛋白 − δ13C蜂蜜
δ13C蛋白 − (−9.7) × 100　(−9.7‰ = 純 C4 糖)
某樣品:蜂蜜 δ13C = −23.0‰、蛋白質 δ13C = −25.0‰
C4 糖 = (−25.0 − (−23.0)) ÷ (−25.0 − (−9.7)) × 100 = (−2.0) ÷ (−15.3) × 100 = 13.1%
依 AOAC 998.12,C4 糖超過 7% 即判定摻假 → 這瓶不合格。

對照一瓶真蜜:蜂蜜 −25.3‰、蛋白質 −25.0‰ → (−25.0 + 25.3) ÷ (−15.3) × 100 = −2.0%,約等於 0 → 合格。
注意負值不是「負的摻假」,而是量測誤差落在 0 附近的正常結果。
判定標準與方法細節請以主管機關公告的檢驗方法為準。

應用二:產地從哪裡來 Where Did It Come From?

同位素反映什麼為什麼有地域性用在哪
δ2H、δ18O當地降水的特徵緯度越高、海拔越高、離海越遠 → 重同位素越少葡萄酒、果汁、橄欖油、米
87Sr / 86Sr土壤下方岩層的年齡與組成生物過程不會改變鍶同位素比 → 忠實反映地質葡萄酒風土、牛肉、茶
δ13C飼料或作物的光合途徑玉米(C4)餵養 vs 牧草(C3)餵養牛肉、乳品的飼養方式
為什麼要同時看好幾個單一個同位素的範圍會重疊——兩個不同產地可能剛好有相近的 δ18O。實務上是把 4–6 個指標合起來比對資料庫,就像不是靠單一特徵而是靠整組特徵來辨識一個人。

應用三:有機、天然,還是合成 Organic, Natural, or Synthetic?

δ15N:有機 vs 化肥
  • 標準是大氣 N2,定義為 0‰
  • 化學氮肥用 Haber–Bosch 從空氣做 → 約 0‰
  • 有機肥經微生物作用,14N 以 NH3 逸失 → 殘留物富集 15N,約 +5 ~ +15‰
  • 所以有機栽培的作物 δ15N 通常較高
14C:生物 vs 石化
  • 14C 半衰期 5730 年
  • 石化原料埋藏數百萬年 → 14C 已衰變殆盡 = 0
  • 穀物、水果等生物來源含現代大氣的 14C
  • → 釀造醋 vs 合成醋酸、天然香草醛 vs 石化香草醛,是有/無的二分判定
δ15N 是證據,不是證明豆科作物自己固定大氣 N2,δ15N 本來就接近 0——不論有沒有施化肥。土壤條件、脫氮作用也會影響。所以它是支持性證據,要配合其他指標與稽核紀錄,不能單獨拿來認定造假。相對地,14C 的判定乾淨得多,因為它問的是一個二分的問題。

隨堂快問 ②:同位素與食品鑑別 Quick Check 2

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1在真蜜裡摻入玉米糖漿(C4),整體的 δ13C 會?
A 往負的方向跑(更負)B 往正的方向跑(較不負)C 完全不變D 變成正值
2檢驗蜂蜜時,為什麼要把蜂蜜裡的蛋白質分離出來一起測 δ13C?
A 蛋白質比較好測B 加進去的糖漿不含蛋白質,蛋白質代表真蜜原本的值C 為了測蛋白質含量D 蛋白質的同位素比較穩定
3某批標示「有機」的蔬菜測得 δ15N = +1‰,低於一般有機作物。可以據此判定它造假嗎?請說出至少一個不能直接下結論的理由。
解答:
1. B — C4 糖的 δ13C(−10 ~ −16‰)比 C3 蜜源(−22 ~ −30‰)高,混合後整體被拉高。選 A 方向弄反。記法:C4 的數值比較「不負」,摻進去就把平均往上拉。這也是為什麼判定式裡的端點是 −9.7‰(純 C4 糖)。
2. B — 糖漿只有糖、沒有蛋白質,所以蛋白質的同位素組成沒有被稀釋。選 A/D 都不是理由。這一題的價值在於內部標準的設計思維:找一個造假動不到的成分當基準——這與第 7 週「一級標準品」要挑穩定、組成明確的物質是同一個道理。
3. 不能 — ① 豆科作物自己固定大氣 N2,δ15N 本來就接近 0;② 土壤本底與脫氮作用會使數值移動;③ 有機肥本身的 δ15N 範圍就很寬(+5 ~ +15‰)。一個數字只回答它自己那一個問題。δ15N 回答「氮從哪裡來」,不是「有沒有依有機規範栽培」。能說出方法的邊界,比會用它更重要。

隨堂快問 ③:週期表的讀法 Quick Check 3

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1下列何者是類金屬 (metalloid)?
A AlB SiC SD Ca
2同一族(直行)的元素,下列何者最相似?
A 原子質量B 原子半徑C 價電子數與化學性質D 中子數
3鈉(第 1 族)與鎂(第 2 族)都是活潑金屬。為什麼鈉更容易失去電子?用價電子的角度說明。
解答:
1. B(Si) — 類金屬沿週期表的階梯線分布:B、Si、Ge、As、Sb、Te。選 A 的同學把鋁當類金屬 —— 鋁是金屬,雖然位置靠近階梯線。這條線是「分界」不是「歸屬」,線的左下是金屬、右上是非金屬,只有壓在線上的那幾個才是類金屬。
2. C — 同族 = 價電子數相同 → 化學性質相似,這正是週期表按族排列的理由。選 A/B/D 都是沿族遞變而非相同的量。記住:族看性質,週期看趨勢。
3. 因為鈉只需失去 1 個電子就達到八隅體 — Na 的價電子組態是 3s1,失去 1 個電子即成為 [Ne];Mg 是 3s2,要失去 2 個。失去第二個電子需要更多能量(逐級游離能遞增)。此題預告第 2 週的游離能。若學生答「因為鈉比較活潑」,那是把現象當成解釋 —— 要問的是為什麼活潑。

有效核電荷與遮蔽 Effective Nuclear Charge & Shielding

定義遮蔽 (shielding):內層電子部分抵消核電荷對外層電子的吸引。
有效核電荷 (Zeff):外層電子實際感受到的淨核電荷,Zeff ≈ Z − 遮蔽電子數。
  • 同週期左→右:質子增加、遮蔽幾乎不變 → Zeff 增大 → 抓得更緊
  • 同族上→下:殼層數增加 → 外層電子離核更遠、遮蔽更多
重點幾乎所有週期性趨勢都能用「Zeff + 殼層數」這兩個因素解釋。

原子半徑 Atomic Radius

  • 同週期左 → 右:半徑減小
    Zeff 增大,電子雲被拉緊
  • 同族上 → 下:半徑增大
    殼層數 n 增加,佔主導

最大:左下角(Fr、Cs)
最小:右上角(He、F)

例:Na (186 pm) > Cl (99 pm);K (227 pm) > Na (186 pm)

例題 4:原子半徑排序 Example 4

例題將下列元素依原子半徑由大到小排序:(a) Na、Mg、K;(b) C、N、Si。
解:
(a) K 在 Na 下方(同族,下 > 上)→ K > Na;Mg 在 Na 右邊(同週期,左 > 右)→ Na > Mg
排序:K > Na > Mg
(b) Si 在 C 下方 → Si > C;N 在 C 右邊 → C > N
排序:Si > C > N
訣竅:先畫出相對位置,「越左下越大、越右上越小」。

游離能 Ionization Energy (IE)

定義游離能:氣態原子移走一個電子所需的最小能量(恆為正值、吸熱):X(g) → X⁺(g) + e⁻。
  • 同週期左 → 右:IE 增大(Zeff 大、半徑小,電子難移走)
  • 同族上 → 下:IE 減小(電子離核遠,好移走)
  • IE 最大:鈍氣(He 為全元素之冠);最小:鹼金屬(Cs、Fr)
重點IE 小 → 易失電子 → 金屬性;IE 大 → 難失電子 → 非金屬性。

游離能的例外 Exceptions: Be/B and N/O

比較趨勢預測實際原因
Be vs BB 較大Be > BB 失去的是能量較高的 2p 電子(Be 為全滿 2s²)
N vs OO 較大N > OO 的 2p⁴ 中有一對配對電子互斥;N 為半滿 2p³ 較穩定
注意同樣的例外也出現在下一週期(Mg/Al、P/S)。關鍵字:全滿 s、半滿 p 的額外穩定性。

離子半徑 Ionic Radius

陽離子:比原子小

  • 失去整個外殼層 + Zeff 相對變大
  • Na (186 pm) → Na⁺ (102 pm)

陰離子:比原子大

  • 電子增加、互斥變大,核拉不住
  • Cl (99 pm) → Cl⁻ (181 pm)
必背「陽小陰大」;等電子系列中,質子越多半徑越小。

例題 5:等電子系列半徑排序 Example 5

例題將 O²⁻、F⁻、Na⁺、Mg²⁺ 依半徑由大到小排序,並說明理由。
解:
四者皆為 10 電子的等電子粒子(組態 [Ne]),差別只在質子數:
O (Z = 8)、F (Z = 9)、Na (Z = 11)、Mg (Z = 12)
電子數相同時,質子越多 → 吸引越強 → 半徑越小:
O²⁻ > F⁻ > Na⁺ > Mg²⁺
(140 pm > 133 pm > 102 pm > 72 pm)

回到本週的錨點 Anchor Answered

第 2 週開場問的是:「檸檬酸鈣 1000 mg」到底補了多少鈣?

用這一週的化學回答

  • 「1000 mg」指的是整個化合物的質量,不是鈣的質量。要知道補到多少鈣,得用化學式算出鈣在其中所占的質量分率。
  • 碳酸鈣 CaCO3(M = 100.1):鈣占 40.08/100.1 = 40% → 1000 mg 含約 400 mg 元素鈣。
  • 檸檬酸鈣 Ca3(C6H5O7)2(M = 498.4):三個鈣占 120.2/498.4 = 24% → 1000 mg 只含約 240 mg 元素鈣。
  • 所以「先猜猜看」的答案是碳酸鈣含鈣較多,約 1.7 倍。(檸檬酸鈣仍有它的優點:不需胃酸即可吸收,適合胃酸不足者——但那是吸收率的問題,不是含量的問題,兩者不能混為一談。)
這個情境幫你理解的化學是化學式是一份組成的合約。看懂它,「1000 mg」這個數字就從一個行銷詞變成一個可以驗算的量——而且你會發現標示上真正該看的是元素鈣那一欄。

本週重點總結 Summary

  • 核種符號 AZX:Z = 質子數、A = 質子 + 中子;同位素質子相同、中子不同
  • 平均原子量 = Σ(同位素質量 × 豐度),所以週期表上的數字不是整數
  • 同位素豐度會隨來源而變——δ13C 抓蜂蜜摻 C4 糖、δ15N 看氮肥、14C 分辨生物與石化來源
  • 有效核電荷解釋一切趨勢:同週期向右變大 → 半徑變小、游離能變大
  • 陽離子比原子小、陰離子比原子大;等電子系列看核電荷排序
  • 離子化合物用電荷平衡寫化學式;多原子離子超過一個要加括號
  • 命名:先陽後陰、過渡金屬加羅馬數字、二元分子用倍數字首
  • 「化合物 1000 mg」≠「元素 1000 mg」 —— 要用質量分率換算
帶走一句話化學式讓你算得出「裡面到底有多少」——這是整個食品標示判讀的起點。
