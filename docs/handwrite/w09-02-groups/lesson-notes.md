# 官能基、鍵型與親水親脂

學習目標：能依官能基與骨架判斷親水親脂趨勢，避免過度生理推論。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 結構，要同時看兩部分

氧、氮與可帶電的基團，可以提供與水作用的機會。大段碳氫骨架則常偏親脂。不能只看到一個氧，就保證整個分子很容易溶於水。

## 2. 親水親脂，是整體平衡

同一分子可能同時有親水頭與親脂尾。碳氫鏈延長，和水的相容性常下降；可電離基團帶電時，水合通常增強。實際溶解度仍受溫度、晶體與其他條件影響。

## 3. 乙醇和長鏈醇，哪個通常更親水

乙醇與長鏈醇都有一個羥基，但後者碳氫鏈更長。其他條件可比較時，哪一個通常在水中的相容性較高？

## 4. 羥基一樣，骨架不一樣

乙醇的短碳鏈讓羥基的親水作用比較明顯。長碳鏈增加親脂部分，不能只用有沒有羥基二分。把兩部分的相對比例一起看，預測才比較合理。

## 5. 雙鍵的π鍵，限制旋轉

單鍵以σ鍵為主，可有轉動，但仍可能有能量障礙。雙鍵包含一個σ鍵與一個π鍵，繞鍵旋轉會破壞π重疊，因此不能像一般單鍵那樣自由轉動，這和順反結構有關。
