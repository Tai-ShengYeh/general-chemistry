# 共軛、吸收與比色定量

學習目標：能解釋共軛與顏色的關係，在適用條件下使用Beer定律。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 共振，不是在兩張圖之間跳

多張共振式是描述同一真實電子分布的工具。原子骨架不搬動，只改電子配置。真實分子是共振混成，不是輪流變成其中一張結構。

## 2. 能階差小，吸收波長較長

光子的能量和波長成反比。相似結構中，共軛延長常讓相關能階差變小，吸收往長波長移。實際顏色還受到基團、溶劑、酸鹼與聚集影響，不能只數雙鍵。

## 3. 吸收藍光，為什麼看起來偏橙

白光穿過某色素溶液，其中藍光吸收較強。你看到的是吸收掉的光，還是剩下透過的光？

## 4. 顏色來自留下的光

透射觀察主要看到未被吸收的光，因此常和強吸收色呈互補關係。真實光譜是寬波段，混合色也更複雜；不把顏色當成只有單一波長。

## 5. Beer定律，要在適用範圍內

比色定量用吸光度等於莫耳吸光係數乘光徑與濃度。波長、物種、溶劑與光徑要一致，還要扣適當空白。濃度太高、散射或化學狀態改變時，不能假設永遠線性。

## 6. 吸光度由0.20變0.40

在已驗證線性範圍內，其他條件相同，標準濃度十微莫耳每公升時吸光度零點二零；未知是零點四零。未知濃度多少？

## 7. 答案：兩倍濃度，但要先驗證條件

零點四除零點二是二，因此未知是二十微莫耳每公升。這個推算依賴相同物種與線性範圍。食品加熱變色還可能是降解、異構化或酸鹼改變，要用證據區分。
