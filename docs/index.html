使用說明

  • 本頁與各週投影片皆為單一 HTML 檔,完全離線可用,雙擊即可以瀏覽器開啟。
  • 因次分析練習可讓學生自行反覆練習:每題先選單位路線、再算數字,答錯時會指出是「方向反了」「漏掉一段」還是「漏掉除以體重」。紀錄只存在學生自己的瀏覽器,不會上傳。
  • 教師專用資源（AI 驗算單解答卷、題庫主檔）不隨網站發佈,請在本機開啟 教師專用.html。
  • 計算專題是第 1 週的延伸:因次分析、密度雙向換算、多段串接、ADI 與 DRIs 計算。第 1 週若 3 小時排不下,可拆成兩次上課;它不佔用 18 週的編號。
  • 每週投影片 40 張上下,含學習目標、分節講解、例題詳解、重點總結、中英名詞對照與課後練習,適合 3 小時課程。
  • 投影片內建列印模式:開啟後按 Ctrl+P,選擇「橫向」即可輸出為講義 PDF 發給學生。
  • 標有 ＋食品錨點 pilot 版 的週次另有擴充版本(加入食品情境例題、學習成果對照與四級評量規準),可擇一使用。
  • 例題解答預設隱藏:停在例題頁時先按一次空白鍵(或點畫面右側)才顯示解答,再按一次才翻頁;列印時解答全部印出。目的是讓學生先自己試算。
  • W1、W3、W5、W8 每個 PART 結尾設有隨堂快問(3 題,2–3 分鐘):個人作答 → 與鄰座說明理由 → 全班表決 → 才看解答。解答內含誘答診斷,說明選錯的人卡在哪個迷思。
  • 每週第 3 張是食品營養錨點(開場提問),倒數第 3 張是錨點回收頁(用本週化學回答它)。兩張要成對使用 —— 問了不答的情境會變成「趣聞」,反而增加認知負荷。
  • 教師可直接以文字編輯器修改各 HTML 檔內容(投影片為 <section class="slide"> 區塊,增刪即可)。
