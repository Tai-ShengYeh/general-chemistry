# 水活性：不是含水量

學習目標：能計算aw並區分含水量，避免以單一數值推定保存安全。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 水活性，有可測量的定義

在同一溫度下，食品上方平衡水蒸氣壓，除以純水蒸氣壓，就是水活性。它反映水的熱力學狀態，不是直接量出一份叫自由水的比例。

## 2. 先達平衡，再比較蒸氣壓

把樣品與氣相放到平衡，量測水的相對蒸氣壓。若平衡相對濕度用百分比表示，水活性等於它除以一百。組成與溫度不同，含水量和水活性的關係也不同。

## 4. 答案：0.601，沒有單位

十四點三除二十三點八，約零點六零一；兩個壓力單位相消。但這個數字本身不能直接宣告食品可以常溫放多久，還要看產品與製程資料。

## 5. 同含水量，不保證同水活性

糖、鹽與食品基質會改變水的化學勢，但實際變化要靠測量或適用的吸濕等溫線。兩包餅乾含水量同為百分之五，不足以直接算出哪一包水活性多少。

## 6. aw低，能保證所有反應都慢嗎

## 7. 不同變化，有不同的水活性曲線

不同微生物耐受性、化學反應與食品結構，對水活性反應不同。很乾也不保證氧化最慢，更不等於污染物已消失。保存設計要把實測水活性、溫度、包裝與驗證一起看。
