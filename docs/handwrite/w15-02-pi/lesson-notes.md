# 等電點與酸凝：電荷會改變

學習目標：能以pH與pI比較淨電荷，分辨酸凝、分解及食品分類界線。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 等電點，是平均淨電荷為零

蛋白質上的可電離基團，會隨pH改變質子化狀態。等電點是平均淨電荷為零的pH，不代表每個基團都沒有電荷，也不代表蛋白質沒有極性。

## 2. 靠近等電點，排斥常減弱

蛋白質接近等電點時，靜電排斥常減弱，可能較易聚集。真正沉澱與否還受濃度、鹽、溫度、表面與製程影響，不能只用pH等於pI就保證一定沉澱。

## 3. pI是4.8，在pH7.0帶什麼電

## 4. 答案：通常淨負電

pH高於等電點，去質子化程度較高，蛋白質通常呈淨負電。這是整體平均淨電荷，不是每個胺基酸側鏈都帶負電。

## 5. 牛奶酸凝，不是把蛋白切斷

酪蛋白微胞是複雜膠體結構。酸化會改變電荷、礦物平衡與微胞交互作用，接近約四點六時常促進酸凝。這主要是聚集與凝膠形成，不等於肽鍵被切成胺基酸。

## 6. 兩個4.6，是同一件事嗎

食品酸度分類常提四點六，酪蛋白等電點也約四點六。它們是否由同一個化學機制決定？請說明各自在描述什麼。

## 7. 相同數字，不是相同理由

食品分類界線與酪蛋白等電點，有不同的定義與依據。數字接近只是巧合。酸凝也不是把pH調回來就保證完全復原，因為聚集、加熱與加工可能帶來不可逆變化。
