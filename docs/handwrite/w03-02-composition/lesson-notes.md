# 元素組成、實驗式與鈉鹽換算

學習目標：能以質量分率換算元素與鹽當量，並推導實驗式及分子式。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 元素標示，要換成化合物

營養標示的鈉，不等於氯化鈉。若假設這些鈉全部來自氯化鈉，就能依莫耳質量比例換算氯化鈉當量。真實食品也可能有其他含鈉化合物。

## 2. 質量分率，分母是整個化合物

鈉的質量分率，是每莫耳氯化鈉中的鈉質量，除以氯化鈉莫耳質量。分子與分母同樣用公克每莫耳，因此分率沒有單位。

## 3. 1800 mg鈉相當於多少鹽

題設把所有鈉換算成氯化鈉當量。標示一千八百毫克鈉，應該乘零點三九三四，還是除以它？

參考答案：約4.58 g氯化鈉當量。

## 4. 鹽的量，會比鈉的量大

一點八公克鈉，乘五十八點四四，再除二十二點九九，約四點五八公克氯化鈉當量。氯化鈉還包含氯，因此總質量會比鈉本身大。

## 5. 實驗式，要先轉莫耳比

假設一百公克樣品，碳四十點零、氫六點七一、氧五十三點二九公克。各自除原子莫耳質量，再除以最小值，得到約一比二比一。實驗式只給最簡整數比例。

## 6. 實驗式CH₂O，分子式一定一樣嗎

實驗式是碳一、氫二、氧一。已知分子莫耳質量約一百八十，實驗式量約三十。分子式要乘幾倍？

作答停頓：HTML 自動暫停；MP4 保留固定思考時間。

參考答案：6倍；C₆H₁₂O₆。

## 7. 答案：六倍，但不能認定結構

一百八十除三十，是六。分子式為碳六、氫十二、氧六。這仍然無法單靠分子式認定一定是葡萄糖，因為不同結構可以有相同分子式。
