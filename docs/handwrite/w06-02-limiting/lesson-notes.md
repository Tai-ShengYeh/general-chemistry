# 限量試劑、剩餘量與產率

學習目標：能判斷限量與剩餘量，解讀產率及異常高值。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 不是最少公克，就是限量

限量試劑是依反應比例最先用完的物質。先把各反應物換成莫耳，再除以各自係數。比較這個值，最小者決定反應能進行幾組。

## 2. 按一組反應來比較

合成氨時，一組需要一份氮氣與三份氫氣。若起始有一莫耳氮氣、兩莫耳氫氣，氫氣不夠完成一整組。不是看兩莫耳比一莫耳大就說氫氣過量。

## 3. 1.00 mol氮氣、2.00 mol氫氣

請各自除以反應式係數。哪個先用完？最多能生成多少莫耳氨？

參考答案：H₂限量，最多1.33 mol NH₃。

## 4. 答案：氫氣限制產量

氫氣的可反應組數較小，所以氫氣是限量試劑。氨的理論產量是一點三三莫耳。氮氣只消耗三分之二莫耳，因此還剩約零點三三三莫耳。

## 5. 理論產量與實際產量

理論產量是指定反應模型、限量試劑完全利用時的上限。實際純產物可能因轉移損失、副反應或未反應完全而較少。表觀產率超過百分之一百時，先查水分、雜質與計算。

## 6. 秤到11 g，理論只有10 g

學生得到濕沉澱十一公克，理論純產物十公克。他說產率百分之一百一十，代表反應比理論更好。這個說法合理嗎？

## 7. 表觀超過，先查秤到了什麼

濕沉澱把水也一起秤進去，不能當成純產物質量。這時百分之一百一十是方法或樣品的警訊。放大食譜也要檢查混合、傳熱與留氣條件，莫耳比放大不保證品質按比例放大。
