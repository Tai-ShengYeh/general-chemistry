# 離子配對、命名與元素含量

學習目標：能以電荷平衡寫化學式，並區分元素與化合物的標示量。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 化學式，先守住電中性

離子化合物的比例，要讓總電荷為零。下標表示組成比例，不是離子的電荷。若多原子離子要用兩個，就先加括號，再把下標寫在外面。

## 2. 名稱、化學式、含量要連起來

先辨認離子與電荷，再寫出化學式，才能計算元素比例。鐵的羅馬數字表示氧化態。氯化鐵三的化學式是三氯化鐵，不是把三寫在鐵的下標。

## 3. 鎂與硝酸根，怎麼配

鎂離子帶正二，硝酸根帶負一。中性化合物需要幾個硝酸根？括號應該放在哪裡？

作答停頓：HTML 自動暫停；MP4 保留固定思考時間。

參考答案：Mg(NO₃)₂。

## 4. 答案：Mg(NO₃)₂

一個鎂離子，配兩個硝酸根。總電荷正二加負二，等於零。括號外的二要乘到整個硝酸根，所以一個式量單位中有兩個氮與六個氧。

## 5. 1000 mg 碳酸鈣，不等於1000 mg鈣

碳酸鈣的莫耳質量約一百點零九公克每莫耳，其中鈣約四十點零八。鈣的質量分率約百分之四十。這裡算的是標示的化合物成分，不是在給補充劑用量建議。

## 6. FeCl₂ 和 FeCl₃ 名稱相同嗎

氯離子的電荷是負一。請分別判斷二氯化鐵與三氯化鐵中，鐵的氧化態。用羅馬數字把兩者區分。

作答停頓：HTML 自動暫停；MP4 保留固定思考時間。

參考答案：氯化鐵(II)與氯化鐵(III)。

## 7. 名稱要交代不同的鐵

二氯化鐵中的鐵是正二，三氯化鐵中是正三。命名分別為氯化鐵二與氯化鐵三。看到食品標示，也要確認標示的是元素量，還是化合物量。
