PART 1

形式電荷

Formal Charge
定義與公式・計算示範・挑選最佳 Lewis 結構

形式電荷的定義 Definition of Formal Charge

定義形式電荷 (formal charge, FC):假設鍵結電子被兩原子均分時,原子「名義上」帶的電荷。
FC = 價電子數 − 未鍵結(孤對)電子數 − ½ × 鍵結電子數
  • 「價電子數」看週期表族數;「孤對電子數」與「鍵結電子數」看畫出的結構
  • FC 是記帳工具,不是原子真實的電荷
  • 檢查:各原子 FC 總和 = 分子為 0;離子 = 離子電荷

形式電荷計算示範 How to Compute FC

以 H–C≡N:(HCN)為例:

原子價電子孤對電子鍵結電子FC
H1021 − 0 − 1 = 0
C4084 − 0 − 4 = 0
N5265 − 2 − 3 = 0
速算法FC = 價電子數 −(孤對電子數 + 鍵的數目)。每一條鍵(不論單雙參)對該原子貢獻「1」。

例題 1:CO2 不同結構的形式電荷 Example 1

例題CO2(16 個價電子)可畫成兩種滿足八隅體的結構:
(i) :Ö=C=Ö:   (ii) :O≡C–Ö:(一端參鍵、一端單鍵)
計算兩結構中各原子的 FC,何者較佳?
解:
(i) 每個 O:6 − 4 − 2 = 0;C:4 − 0 − 4 = 0 → FC 全為 0
(ii) 參鍵 O:6 − 2 − 3 = +1;C:0;單鍵 O:6 − 6 − 1 = −1
兩者 FC 總和皆為 0(✓ 中性分子),但 (i) 每個原子 FC 皆為 0 →結構 (i) 較佳,與實驗(兩鍵等長)相符。

用 FC 挑選最佳 Lewis 結構 Choosing the Best Structure

  1. 各原子 FC 越接近 0 越好(FC 為 0 的原子越多越好)
  2. 避免相鄰原子帶同號 FC;避免出現大的 FC(±2 以上)
  3. 若必須有負 FC,應放在電負度較大的原子上
流程畫出所有滿足八隅體的合理結構 → 逐一算 FC → 依上列規則排優劣。

例題 2:OCN− 的最佳結構 Example 2

例題氰酸根 OCN−(16 電子,骨架 O–C–N)有三種八隅體結構:
(i) :Ö=C=N̈:⁻  (ii) :O≡C–N̈:⁻  (iii) :Ö–C≡N:⁻。判斷何者貢獻最大。
解:計算 FC(O, C, N):
(i) O:0,C:0,N:−1
(ii) O:+1,C:0,N:−2
(iii) O:−1,C:0,N:0
(ii) 出現 +1 與 −2 → 最差。(i) 與 (iii) 比較:負電荷放電負度較大的 O 上較佳?O(3.5)> N(3.0)→ 結構 (iii) 貢獻最大,(i) 次之,(ii) 最小。

3為什麼「形式電荷絕對值總和最小」的結構通常最好?這個規則背後的物理意義是什麼?

PART 2

共振

Resonance
電子離域・共振結構・共振混成體・鍵級與實測鍵長

共振的概念 Concept of Resonance

定義當一個分子/離子可畫出兩個以上僅電子位置不同(原子位置相同)的合理 Lewis 結構時,這些結構稱為共振結構 (resonance structures),以雙箭頭 ↔ 連接。
  • 真實分子是所有共振結構的平均:共振混成體 (resonance hybrid)
  • 本質:電子(通常是 π 電子)離域 (delocalization) 分布在多個原子間
  • 離域使能量降低 → 共振使分子更穩定

畫共振結構的規則 Rules for Drawing Resonance Structures

  • 只能移動電子(通常是 π 電子與孤對電子),原子位置不可動
  • 每個共振結構都必須是合理的 Lewis 結構(電子數正確、八隅體規則)
  • 各結構的總電荷相同、未成對電子數相同
  • 以雙箭頭 ↔ 連接(注意:不是平衡符號 ⇌!)
辨析↔ 表示「同一物種的不同畫法」;⇌ 表示「兩種真實物種之間的動態平衡」。移動了原子就不是共振,而是異構物或不同反應。

例題 3:O3 的共振結構 Example 3

例題畫出臭氧 O3(18 電子)的共振結構,並預測兩個 O–O 鍵的鍵長關係。
解:骨架 O–O–O,依五步驟得中心 O 不足八隅體 → 造一個雙鍵,雙鍵可在左或右:
:Ö–Ö=Ö:  ↔  :Ö=Ö–Ö:
兩結構能量相同、貢獻相等 → 真實 O3 是兩者的混成:
兩鍵完全等價,鍵級 = (1+2)/2 = 1.5;實測兩鍵皆為 128 pm,介於 O–O 單鍵(148 pm)與 O=O 雙鍵(121 pm)之間 ✓

例題 4:NO3− 與 CO32− 的共振 Example 4

例題NO3−(24 電子)與 CO32−(24 電子)各有幾個共振結構?鍵級各為何?
解:兩者結構同型:中心原子接 3 個 O,其中 1 個雙鍵、2 個單鍵。
雙鍵可放在 3 個 O 的任一個 → 各有 3 個共振結構。
鍵級 = 總鍵數 ÷ 鍵的位置數 = (2+1+1)/3 = 4/3 ≈ 1.33
預測:三個鍵完全等長,長度介於單鍵與雙鍵之間 — 與實驗相符(NO3− 三鍵皆 124 pm)。

共振的常見誤解 Misconceptions about Resonance

誤解 1「分子在各共振結構之間快速跳動」— 錯!真實分子永遠只有一種結構(混成體),不會來回變換。
誤解 2「共振結構是真實存在的異構物」— 錯!單一共振結構只是紙上的近似,混成體才接近真實。
比喻騾 = 馬與驢的「混成」:騾不是一下當馬、一下當驢;馬和驢也各自不是騾。共振混成體亦然。

隨堂快問 ②:共振 Quick Check 2

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1O3 有兩個共振結構。真實的臭氧分子是?
A 兩種結構各半的混合物B 在兩種結構間快速跳動C 兩鍵等長的單一結構D 一長一短兩種鍵
2NO3− 有三個共振結構,其 N–O 鍵級為?
A 1B 1.33C 1.5D 2
3如果共振只是「紙上的畫法」,那為什麼實測鍵長真的介於單鍵與雙鍵之間?
解答:
1. C — 真實結構是單一的共振混成體,兩個 O–O 鍵完全等長。選 A/B 是最頑固的兩個迷思。共振不是混合物,也不是快速切換 —— 分子隨時都是那一個結構,只是我們的 Lewis 記號畫不出來。就像騾不是「一下是馬一下是驢」。
2. B(1.33) — 4 個成鍵電子對分給 3 個 N–O 位置 → 4/3 ≈ 1.33。算法:總鍵數 ÷ 位置數。O3 是 3/2 = 1.5、NO3− 是 4/3。鍵級能直接預測鍵長排序,是很好用的檢查。
3. 因為電子確實是離域的 — 實驗看到的等長鍵,正說明電子不是定域在某兩個原子之間,而是散布在整個分子骨架上。所以「共振是紙上的畫法」這句話要講清楚:限制在人類的記號系統,不在自然界。分子沒有問題,是 Lewis 結構這套語言不夠用。

Exceptions to the Octet Rule
奇電子分子・缺電子分子・擴充八隅體

三類例外總覽 Three Types of Exceptions

類型特徵例子
奇電子分子
odd-electron molecules		總價電子為奇數,必有一未成對電子(自由基)NO、NO2、ClO2

奇電子分子 Odd-Electron Molecules (Free Radicals)

  • NO:11 個價電子 → 不可能人人八隅體;結構 :N=Ö:(N 上 1 對孤對 + 1 個單電子)
  • NO2:17 個價電子;單電子通常放在 N 上(電負度較小者)
  • 含未成對電子的物種稱自由基 (free radical):活性高、易二聚(2NO2 ⇌ N2O4)
  • NO 是重要的生理訊息分子;NOx 是空氣汙染物
判斷總價電子數是奇數 → 一定是八隅體例外,先確認電子數再動筆!

缺電子分子 Electron-Deficient Molecules

BF3(24 電子)

  • B 周圍僅 3 鍵 = 6 電子
  • 畫 B=F 雙鍵會使 F 帶 +1(電負度最大的 F 帶正 FC → 不合理)
  • B 的空軌域使 BF3 是強路易斯酸:BF3 + :NH3 → F3B–NH3

BeH2(4 電子)

  • Be 周圍僅 2 鍵 = 4 電子
  • H 無孤對可移入,無法補足
  • Be、B 化合物是典型缺電子例子

擴充八隅體 Expanded Octets (Hypervalence)

  • 第 3 週期(含)以後的元素(P、S、Cl、Xe⋯)可容納超過 8 個電子
  • PCl5(40e):P 形成 5 鍵 = 10 電子
  • SF6(48e):S 形成 6 鍵 = 12 電子
  • XeF4(36e):Xe 形成 4 鍵 + 2 孤對 = 12 電子
注意第 2 週期元素(C、N、O、F)絕不可擴充八隅體 — 沒有可用的 d 軌域、原子太小。看到「NF5」「OF4」這種結構就是錯的!

例題 5:畫例外分子的 Lewis 結構 Example 5

例題畫出 (a) XeF4 與 (b) I3− 的 Lewis 結構,並數中心原子的電子數。
解:
(a) 價電子 = 8 + 4(7) = 36(18 對)。骨架 4 個 Xe–F(4 對),每個 F 補 3 對(12 對),剩 2 對放中心 Xe。
→ Xe:4 鍵 + 2 孤對 = 12 電子(擴充八隅體)

→ 中心 I:2 鍵 + 3 孤對 = 10 電子;整體加 [ ]−

鍵能與反應熱

Bond Energies and ΔH
平均鍵能・ΔH ≈ Σ斷鍵 − Σ生成鍵・與生成焓法比較

鍵能 Bond Energy

定義鍵能 (bond energy / bond dissociation energy):氣態下斷開 1 mol 某化學鍵所需的能量(恆為正值)。
例:H2(g) → 2H(g),D(H–H) = 436 kJ/mol
  • 斷鍵吸熱(+);形成鍵放熱(−)
  • 同種鍵在不同分子中略有差異 → 表列值為平均鍵能
  • 鍵能越大 → 鍵越強、越短、越難斷

  • 斷鍵總能量 < 成鍵總能量 → ΔH < 0(放熱)
  • 只適用氣相反應;因為用「平均」鍵能,結果是估計值

例題 7:H2 + Cl2 → 2HCl Example 7

例題用鍵能估算 H2(g) + Cl2(g) → 2HCl(g) 的 ΔH。
(D:H–H 436、Cl–Cl 243、H–Cl 430 kJ/mol)
解:
斷鍵:1 mol H–H + 1 mol Cl–Cl = 436 + 243 = 679 kJ
成鍵:2 mol H–Cl = 2 × 430 = 860 kJ
ΔH ≈ 679 − 860 = −181 kJ
放熱反應;與實驗值 −185 kJ 相近(誤差來自平均鍵能)。

例題 8:甲烷燃燒 Example 8

例題估算 CH4(g) + 2O2(g) → CO2(g) + 2H2O(g) 的 ΔH。
(D:C–H 415、O=O 498、C=O(CO2) 799、O–H 464 kJ/mol)
解:先畫 Lewis 結構數鍵:CH4 有 4 個 C–H;CO2 有 2 個 C=O;H2O 有 2 個 O–H。
斷鍵:4(415) + 2(498) = 1660 + 996 = 2656 kJ
成鍵:2(799) + 4(464) = 1598 + 1856 = 3454 kJ
ΔH ≈ 2656 − 3454 = −798 kJ
實驗值約 −802 kJ — 鍵能法的估計相當接近。

鍵能法 vs 生成焓法 Bond Energies vs. ΔH°f

鍵能法生成焓法(Hess 定律)
公式Σ斷鍵 − Σ生成鍵ΣΔH°f(生成物) − ΣΔH°f(反應物)
準確度估計值(平均鍵能)準確(實驗數據)

優點無表列 ΔH°f 時仍可估算;直觀連結「結構↔能量」精確、通用
注意兩法「Σ」的方向相反:鍵能法是「反應物 − 生成物」概念(斷−成),生成焓法是「生成物 − 反應物」。別背混!

隨堂快問 ④:鍵能與反應熱 Quick Check 4

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1用鍵能估算 ΔH 的公式是?

2用平均鍵能算出的 ΔH 與實驗值常有差異,主因是?
A 鍵能表抄錯B 平均鍵能是跨許多分子的平均值,不是該分子的真實值C 能量不守恆D 溫度不同
3為什麼鍵能法只能用於氣相反應?若反應物是液態會有什麼問題?
解答:
1. A — ΔH ≈ Σ(斷鍵吸能) − Σ(成鍵放能)。方向記法:斷鍵吸能為正、成鍵放能為負,所以是「斷 − 成」。選 B 的同學算出的每個 ΔH 都會差一個負號 —— 檢查方式:燃燒反應必須是負值。
2. B — 例如 C–H 在甲烷與在乙醇中的實際鍵能並不相同,表上給的是平均值。所以鍵能法是估算,誤差常有數十 kJ。要精確就用 ΔH°f 法 —— 這也是兩種方法並存的理由。
3. 因為鍵能定義在氣態 — 鍵能是氣態分子斷鍵所需的能量。若反應物是液態,還要額外加上汽化熱才能進入氣相。少算那一項,結果會系統性偏差。這與 W06「熱化學方程式一定要標狀態」是同一件事的另一面。
PART 5

晶格能與 Born-Haber 循環

Lattice Energy and the Born-Haber Cycle
循環步驟拆解・NaCl 計算・影響晶格能的因素

為什麼需要 Born-Haber 循環? Why Born-Haber?

  • 晶格能無法直接測量(無法把晶體「拆」成氣態離子來量熱)
  • 解法:利用 Hess 定律 — 把 NaCl(s) 的生成拆成一連串可測量的步驟
  • 此熱力學循環稱 Born-Haber 循環 (Born-Haber cycle)
Hess 定律複習ΔH 是狀態函數:總反應的 ΔH = 各步驟 ΔH 之和,與路徑無關。

Born-Haber 循環:步驟拆解(NaCl) Steps of the Cycle

步驟反應對應能量ΔH (kJ/mol)
① 昇華Na(s) → Na(g)昇華熱 ΔHs+108
② 解離½Cl2(g) → Cl(g)½ 鍵能+122
③ 游離Na(g) → Na+(g) + e−游離能 IE1+496
④ 得電子Cl(g) + e− → Cl−(g)電子親和力 EA−349
⑤ 成晶體Na+(g) + Cl−(g) → NaCl(s)−ΔHlattice?
總和Na(s) + ½Cl2(g) → NaCl(s)生成焓 ΔH°f−411

例題 9:計算 NaCl 的晶格能 Example 9

例題利用上頁數據,求 NaCl 的晶格能 ΔHlattice(NaCl(s) → Na+(g) + Cl−(g))。
解:依 Hess 定律,①+②+③+④+⑤ = 總反應:
ΔH°f = ΔHs + ½D + IE1 + EA + (−ΔHlattice)
−411 = 108 + 122 + 496 + (−349) − ΔHlattice
−411 = 377 − ΔHlattice
ΔHlattice = 377 + 411 = +788 kJ/mol
巨大的晶格能是離子化合物能夠形成的主要能量來源(光靠「Na 給 Cl 電子」其實是吸熱的!)。

註:文獻值隨 EA(Cl) 取值略有差異(本課程採 −349,得 NaCl 788;部分教科書採 −368,得 769),比較大小不受影響。

例題 10:晶格能與熔點排序 Example 10

例題(a) 排序晶格能:KCl、MgO、NaF、MgF2(由大到小)。
(b) 預測 MgO 與 NaF 何者熔點較高?
解:
(a) 電荷乘積:MgO = 4、MgF2 = 2、NaF = 1、KCl = 1 → MgO > MgF2 > (NaF, KCl)
NaF 與 KCl:Na+ < K+、F− < Cl− → NaF 的 d 較小 → NaF > KCl
排序:MgO > MgF2 > NaF > KCl
(b) 晶格能 MgO ≫ NaF → MgO 熔點較高(實測 2852 °C vs 993 °C ✓)

隨堂快問 ⑤:Born-Haber 循環 Quick Check 5

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1Born-Haber 循環的理論依據是?
A 質量守恆B Hess 定律(焓是狀態函數)C 八隅體規則D 電中性原理
2下列哪一項在 Born-Haber 循環中是放熱的?
A 昇華 Na(s) → Na(g)B 游離 Na(g) → Na+ + e−C 解離 ½Cl2 → ClD 形成晶格 Na+(g) + Cl−(g) → NaCl(s)
3晶格能無法直接測量。Born-Haber 循環怎麼幫你得到它?
解答:
1. B — 循環之所以成立,就是因為焓與路徑無關,繞一圈總和必須相等。所以 Born-Haber 不是新原理,只是 Hess 定律的一個特定應用。看懂這一點,就不必背循環的形狀 —— 自己畫得出來。
2. D — 形成晶格是強烈放熱;昇華、游離、解離都要吸熱。整個循環中只有電子親和力與晶格能是放熱項,而晶格能是唯一夠大到讓整體變負的那一項。這也回答了 W10 的第 3 題。
3. 用其他可測的量把它逼出來 — 昇華熱、游離能、解離能、電子親和力、生成焓都可測。把循環的等式列出來,晶格能就是唯一的未知數,移項即得。這是本週最重要的方法論:測不到的量,可以用測得到的量圍出來 —— 與 W06 用 Hess 定律算 C → CO 是同一招。

回到本週的錨點 Anchor Answered

第 11 週開場問的是:同一種色素分子,在不同酸鹼度下可以是紅、紫、藍甚至綠。分子沒換,顏色為什麼會換?

用這一週的化學回答

  • 換的是質子。花青素上的 OH 在不同 pH 下得到或失去 H+ —— 這就是「差別在哪一個原子」的答案。
  • 得失質子改變了分子的共振結構與離域範圍:酸性下是離域良好的紅色陽離子形式,pH 升高後去質子化,離域方式跟著改變。
  • 共軛/離域範圍變了 → HOMO–LUMO 能隙變了 → 吸收的波長變了 → 看到的顏色就變了(接回 W7 的 E = hν)。
  • 同一個原理:酸鹼指示劑變色、紫甘藍加醋變紅加小蘇打變藍綠,機制完全一樣。
這個情境幫你理解的化學是共振不是「畫幾個結構取個平均」的紙上作業。離域範圍決定能隙,能隙決定顏色 —— 你其實看得到共振,它就在紫甘藍汁裡。

本週重點總結(上) Summary (1/2)

  • 形式電荷:FC = 價電子 − 孤對電子 − ½鍵結電子;總和 = 分子/離子電荷
  • 最佳結構:FC 接近 0;負 FC 放電負度大的原子
  • 共振:電子位置不同的等價結構 ↔;真實分子是混成體,等價鍵等長
  • 平均鍵級:總鍵數 ÷ 位置數(O3:1.5;NO3−:1.33)
  • 八隅體例外:奇電子(NO)、缺電子(BF3)、擴充(SF6,限第 3 週期後)

本週重點總結(下) Summary (2/2)

  • 鍵能:斷 1 mol 鍵所需能量;斷鍵吸熱、成鍵放熱
  • 估算反應熱:ΔH ≈ Σ斷鍵 − Σ生成鍵(僅氣相、為估計值)
  • Born-Haber 循環:昇華 + 解離 + 游離 + 電子親和 + 成晶格 = 生成焓
  • 晶格能:由循環間接求得;∝ Q+Q−/d,電荷優先、距離其次
  • 晶格能大 → 熔點高、硬度大、較難溶
