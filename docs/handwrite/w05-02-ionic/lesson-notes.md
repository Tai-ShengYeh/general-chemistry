# 淨離子式與電子去向

學習目標：能刪除旁觀離子，並正確辨認氧化劑與還原劑。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 反應類型，要看真正改變的粒子

沉澱是形成難溶固體，酸鹼反應追蹤質子轉移，氧化還原則追蹤電子收支。某些反應可能同時有多種特徵，分類是幫助理解，不是互斥的盒子。

## 2. 離子式，只留下參與變化者

水溶液中的硝酸銀與氯化鈉，產生氯化銀沉澱。可溶強電解質拆成離子，固體、弱電解質與水不要任意拆開。鈉離子與硝酸根前後相同，可消去。

## 3. 哪兩種是旁觀離子

在硝酸銀與氯化鈉的水溶液反應中，銀離子和氯離子形成沉澱。剩下哪兩種離子，能從完全離子式兩側消去？

參考答案：Na⁺與NO₃⁻。

## 4. 答案：消去鈉與硝酸根

消去兩側相同的鈉離子與硝酸根，得到銀離子加氯離子，形成氯化銀固體。檢查總電荷零，銀和氯原子也各一。

## 5. 氧化，是失去電子

鋅失去兩個電子變成鋅離子，是氧化。銅離子得到這兩個電子變成銅，是還原。鋅使另一方還原，所以鋅是還原劑；氧化劑自己則被還原。

## 6. 氧化劑自己會被氧化嗎

鋅和銅離子反應時，銅離子得到電子。誰是氧化劑？氧化劑自己經歷什麼變化？

參考答案：Cu²⁺是氧化劑，自己被還原。

## 7. 名稱說的是對別人的作用

銅離子是氧化劑，因為它使鋅被氧化；銅離子自己得到電子而被還原。把誰得電子、誰失電子先寫下來，名稱就不容易顛倒。
