## 這是什麼

一套為**食品營養系**設計的普通化學教材，16 個教學週 + 2 個考試週。

每一週從一個食品營養的問題出發，用化學回答它，最後回到那個問題——
化學是**詮釋食品現象的透鏡**，不是講完之後才貼上的應用。

課程內容依食品營養系下游四門課（分析化學、生物化學、食品化學、營養學）的實際需求編排，
包含**酸鹼、pH、緩衝、氧化還原**這些一般普化常被排在下學期、
但食品營養系只修一學期就必須具備的基礎。

每個檔案都是**單一 HTML**，離線可用：下載後直接用瀏覽器開啟，或 `Ctrl+P` 印成講義。
不需要安裝任何東西，沒有外部相依。

## 各週的錨點問題

| 週 | 主題 | 錨點 |
|---|---|---|
| 1 | 測量、有效數字與不確定度 | 營養標示的「糖 5.2 g」可信到第幾位？ |
| 1 延伸 | 計算專題：單位、密度與劑量評估 | 一客牛排的瘦肉精殘留，佔每日容許量多少？ |
| 2 | 物質、原子、離子與命名 | 「檸檬酸鈣 1000 mg」到底補了多少鈣？ |
| 3 | 莫耳與化學式 | 標示「鈉 1800 mg」等於幾克鹽？ |
| 4 | 溶液濃度與稀釋 | 生理食鹽水為什麼是 0.9%？ |
| 5 | 化學反應與四大反應類型 | 小蘇打為什麼能讓蛋糕膨？ |
| 6 | 化學計量、限量試劑與產率 | 家庭配方放大 20 倍，為什麼失敗？ |
| 7 | 滴定與定量分析 | 一瓶油「壞了」沒有？ |
| 8 | 熱化學 | 標示的大卡是把食物燒掉量到的嗎？ |
| 9 | 化學鍵、官能基與分子結構 | 為什麼維生素 A 存在肝臟，維生素 C 尿出去？ |
| 10 | 分子極性、共軛與顏色 | 胡蘿蔔為什麼是橙色？煮久了為什麼變色？ |
| 11 | 分子間作用力與相變 | 蛋白質為什麼一加熱就凝固？巧克力為什麼起霜？ |
| 12 | 溶液與依數性質 | 冰淇淋為什麼不會結成冰塊？ |
| 13 | 膠體、乳化與水活性 | 美乃滋為什麼不分層？蜜餞為什麼不會壞？ |
| 14 | 化學平衡與酸鹼 I | 食品法規為什麼以 pH 4.6 分界？ |
| 15 | 酸鹼 II：緩衝與等電點 | 牛奶加酸為什麼會凝固？優格怎麼形成的？ |
| 16 | 氧化還原、脂質氧化與抗氧化 | 油放久為什麼有油耗味？蘋果為什麼變褐？ |

## 每一週的結構

- **開場錨點**：一個具體的食品營養問題
- **PART 1–5**：概念、例題、手繪向量圖解
- **隨堂快問**：每個 PART 結尾三題——①迷思診斷 ②概念辨析 ③開放產出
- **錨點回收**：用本週的化學回答開場的問題，並說明「這個情境幫你理解了哪個概念」
- **重點總結・名詞對照・課後練習**

投影片的解答預設是**收合**的：按一次 `→` 展開解答，再按一次才翻頁；
列印時解答一律印出。

## 給教師的說明

- 題庫、課後精熟測驗的題目與解答、教師卷、互動平台匯入檔**不在本 repo**——

  會隨公告版本改變，**教學前請以主管機關現行公告為準**。
