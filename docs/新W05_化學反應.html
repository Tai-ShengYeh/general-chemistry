PART 5.1

化學反應式與平衡

Writing and Balancing Chemical Equations
反應式的意義・狀態符號・平衡原則與步驟

化學反應式的意義 Chemical Equations

定義化學反應式 (chemical equation):以化學式與係數表示反應的符號語言。
反應物 (reactants) → 生成物 (products)
狀態符號(s)(l)(g)(aq)
意義固體 solid液體 liquid氣體 gas水溶液 aqueous
  • 「→」讀作「生成」;可逆反應用「⇌」
  • 條件(加熱 Δ、催化劑)可註於箭頭上方

係數傳達的訊息 Information in an Equation

CH4(g) + 2O2(g) → CO2(g) + 2H2O(l)
  • 分子層次:1 個 CH4 分子與 2 個 O2 分子反應
  • 莫耳層次:1 mol CH4 與 2 mol O2 反應,生成 1 mol CO2 與 2 mol H2O
  • 係數比 = 分子個數比 = 莫耳數比(下週化學計量的基礎)
  • 係數比不是質量比!

平衡反應式的原則 Principles of Balancing

  • 依據質量守恆定律:反應前後各元素的原子數必須相等
  • 只能調整係數 (coefficients),絕不可更改化學式的下標
  • 係數應化為最簡整數比
  • 係數 1 慣例上省略不寫
注意把 H2O 改成 H2O2 來「平衡」是大錯 — 改下標就變成另一種物質!

平衡步驟(觀察法) Balancing by Inspection

  1. 寫出正確的反應物與生成物化學式(骨架方程式)
  2. 從出現次數最少、最複雜的元素開始平衡
  3. 多原子離子若反應前後不變,可視為一個整體
  4. 單質(如 O2、Fe)留到最後平衡
  5. 檢查:逐一清點各元素原子數;必要時將分數係數同乘化整

例題 1:平衡反應式 Example 1

例題平衡下列反應式:
(a) N2(g) + H2(g) → NH3(g)   (b) Al(s) + O2(g) → Al2O3(s)
解:
(a) 先平衡 N:NH3 前加 2 → N2 + H2 → 2NH3(右側 H = 6)
    再平衡 H:H2 前加 3 → N2(g) + 3H2(g) → 2NH3(g) ✓
(b) 平衡 O:最小公倍數 6 → 3O2 對 2Al2O3(O 各 6)
    平衡 Al:右側 4 個 → Al 前加 4 → 4Al(s) + 3O2(g) → 2Al2O3(s) ✓

例題 2:平衡燃燒反應 Example 2

例題平衡乙烷的燃燒反應:C2H6(g) + O2(g) → CO2(g) + H2O(g)
解:順序:C → H → O(O2 是單質,最後平衡)
① C:2 → CO2 前加 2  ② H:6 → H2O 前加 3
③ 右側 O = 4 + 3 = 7 → O2 前需 7/2:C2H6 + (7/2)O2 → 2CO2 + 3H2O
④ 全式 × 2 化為整數:2C2H6(g) + 7O2(g) → 4CO2(g) + 6H2O(g)
檢查:C 4=4、H 12=12、O 14=14 ✓
技巧碳氫化合物燃燒:固定順序「C → H → O」幾乎一定成功。

隨堂快問 ①:反應式與平衡 Quick Check 1

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1平衡 H2 + O2 → H2O 時,下列做法何者正確?
A 把 H2O 改成 H2O2B 在 H2O 前加係數 2C 把 O2 改成 OD 兩邊各加一個 O
22H2 + O2 → 2H2O。下列敘述何者正確?
A 2 g H2 配 1 g O2B 2 mol H2 配 1 mol O2C 質量比為 2 : 1D 反應後總分子數不變
3為什麼平衡反應式時只能改係數,不能改下標?
解答:
1. B — 只調整係數,不動化學式。選 A/C 的同學為了配平而改了物質本身 —— H2O2 是過氧化氫,不是水。這是最嚴重的一種錯:方程式配平了,但描述的已經不是原來那個反應。
2. B — 係數是莫耳比(同溫同壓下也是氣體體積比)。選 A/C 把係數當質量比:2 mol H2 = 4.03 g、1 mol O2 = 32.00 g,質量比是 1 : 7.94。選 D 錯在 3 個分子變成 2 個 —— 質量守恆,分子數不守恆。[M03]
3. 因為下標代表物質的身分 — 改下標等於換成另一種物質;改係數只是改「用了幾個」。配平的前提是反應物與產物已經確定,配平只能調整數量。延伸:所以配平前一定要先確認產物是什麼。這也是為什麼「先寫出正確的反應式」比「會配平」更重要。
PART 5.2

電解質與離子方程式

Electrolytes and Ionic Equations
強/弱電解質・分子方程式・完全離子式・淨離子式

電解質與非電解質 Electrolytes and Nonelectrolytes

定義電解質 (electrolyte):溶於水後解離出離子、使溶液導電的物質。
非電解質 (nonelectrolyte):溶於水不解離、溶液不導電的物質。
  • 電解質:酸、鹼、鹽類(NaCl、HCl、NaOH⋯)
  • 非電解質:糖、酒精、尿素等多數分子化合物
  • 導電原因:溶液中有可自由移動的離子

強電解質與弱電解質 Strong vs. Weak Electrolytes

強電解質 strong弱電解質 weak非電解質 non-
解離程度~100% 完全解離部分解離(⇌)不解離
導電性強弱不導電
例子強酸、強鹼、可溶性鹽弱酸(CH3COOH)、弱鹼(NH3)蔗糖、乙醇
方程式寫法拆成離子保留分子式保留分子式
重點NaCl(aq) 實際上是 Na+(aq) + Cl−(aq);醋酸則以 CH3COOH ⇌ CH3COO− + H+ 部分解離。

三種方程式 Molecular, Complete Ionic, Net Ionic

旁觀離子 Spectator Ions

定義旁觀離子 (spectator ions):反應前後形態完全不變的離子,在完全離子方程式兩邊同時出現,可消去。
  • 它們留在溶液中「圍觀」,不參與化學變化
  • 淨離子方程式凸顯反應的本質,不同組合的反應可能有相同的淨離子式
  • 檢查:淨離子方程式的原子數與總電荷都要平衡

例題 3:寫出淨離子方程式 Example 3

例題硝酸銀與氯化鈉水溶液混合,生成氯化銀沉澱。寫出三種方程式。
解:
分子方程式:AgNO3(aq) + NaCl(aq) → AgCl(s) + NaNO3(aq)
完全離子式:Ag+ + NO3− + Na+ + Cl− → AgCl(s) + Na+ + NO3−
消去旁觀離子 Na+、NO3−:
淨離子式:Ag+(aq) + Cl−(aq) → AgCl(s)
檢查:電荷 (+1)+(−1) = 0 = 右側 ✓

隨堂快問 ②:電解質與淨離子式 Quick Check 2

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1下列何者是強電解質?
A 醋酸 CH3COOHB 蔗糖C NaClD 乙醇
2寫淨離子方程式時,下列何者不可拆成離子?
A 水溶液中的 NaClB 水溶液中的 HClC 沉澱的 AgClD 水溶液中的 KNO3
3NaCl 水溶液會導電,固體 NaCl 卻不導電。為什麼?
解答:
1. C — 強電解質 = 在水中幾乎完全解離成離子。選 A 的同學把「酸」當成「強電解質」—— 醋酸是弱電解質,只有少部分解離。強弱看的是解離程度,不是酸鹼性,也不是濃度。
2. C — 沉澱、弱電解質、氣體、水都不拆。選 B 的同學以為酸都要拆 —— 只有強酸才拆。判準是:它在水中是不是以離子形式存在?AgCl 是固體,離子被鎖在晶格裡。
3. 因為固體中離子被鎖在晶格,不能移動 — 導電需要可自由移動的帶電粒子。溶解後 Na+ 與 Cl− 分散於水中可以移動;熔融態同樣能導電。所以判斷導電性要問兩件事:有沒有離子、離子能不能動。少問第二個,就會誤以為固體鹽也導電。
PART 5.3

沉澱反應

Precipitation Reactions
溶解度規則・沉澱的預測

沉澱反應 Precipitation Reactions

定義沉澱反應:兩種可溶性鹽的水溶液混合,陰陽離子交換後生成不溶性固體(沉澱,precipitate)的反應。
  • 屬於複分解反應 (double displacement / metathesis):AX + BY → AY + BX
  • 判斷是否沉澱 → 查溶解度規則 (solubility rules)
  • 應用:離子檢驗、水處理、重量分析(下週)

溶解度規則(必背) Solubility Rules

離子溶解性重要例外
第 1 族(Na+, K+⋯)、NH4+皆可溶無
NO3−、C2H3O2−皆可溶無
Cl−、Br−、I−多可溶Ag+、Pb2+、Hg22+ 不溶
SO42−多可溶Ba2+、Pb2+、Ca2+、Sr2+ 不/微溶
CO32−、PO43−、S2−多不溶第 1 族與 NH4+ 鹽可溶
OH−多不溶第 1 族可溶;Ba2+、Ca2+ 微溶
口訣「硝酸鹽、醋酸鹽、鹼金屬鹽、銨鹽 — 全都可溶」先記住,再記鹵化物與硫酸鹽的例外。

沉澱預測步驟 Predicting Precipitates

  1. 寫出兩溶液中的所有離子
  2. 交換配對:陽離子 A + 陰離子 Y、陽離子 B + 陰離子 X
  3. 用溶解度規則檢查兩個新組合:有不溶者 → 生成沉澱
  4. 兩個組合都可溶 → 無反應 (no reaction, NR)
  5. 寫出平衡的分子方程式與淨離子方程式

例題 4:沉澱預測(一) Example 4

例題混合 Ba(NO3)2(aq) 與 Na2SO4(aq),是否產生沉澱?寫出分子與淨離子方程式。
解:離子:Ba2+、NO3−、Na+、SO42−
交換配對:BaSO4(硫酸鹽例外:Ba2+ 不溶)、NaNO3(硝酸鹽可溶)
分子方程式:Ba(NO3)2(aq) + Na2SO4(aq) → BaSO4(s) + 2NaNO3(aq)
淨離子式:Ba2+(aq) + SO42−(aq) → BaSO4(s)(白色沉澱)

例題 5:沉澱預測(二) Example 5

例題判斷下列混合是否反應:
(a) Pb(NO3)2(aq) + KI(aq)   (b) KCl(aq) + NaNO3(aq)
解:
(a) 配對:PbI2(碘化物例外:Pb2+ 不溶)、KNO3(可溶)→ 有反應
    Pb(NO3)2 + 2KI → PbI2(s) + 2KNO3;淨離子式:Pb2+ + 2I− → PbI2(s)(亮黃色)
(b) 配對:KNO3、NaCl 皆可溶 → 無反應 (NR),所有離子皆為旁觀離子

沉澱反應在食品分析:測食鹽含量 Mohr Titration

問題泡麵標示「鈉 1800 mg」—— 廠商是怎麼測出來的?答案就是你剛學的沉澱反應。
步驟反應看到什麼
滴定Ag+ + Cl− → AgCl(s)白色沉澱不斷生成
終點2Ag+ + CrO42− → Ag2CrO4(s)磚紅色出現且不褪
為什麼行得通AgCl 的溶解度(1.3×10−5 M)比 Ag2CrO4(6.5×10−5 M)小約 5 倍 → Cl− 一定先被沉澱乾淨,多滴的那一滴 Ag+ 才輪得到鉻酸根。指示劑本身就是一個沉澱反應。
接回第 3 週滴定算出 n(Cl−) → n(NaCl) → 乘 39.3% 得鈉的 mg 數,就是營養標示上那個數字。(條件:pH 6.5–10。太酸鉻酸根會轉成重鉻酸根,太鹼則 Ag+ 生成 Ag2O 沉澱。)

隨堂快問 ③:沉澱預測 Quick Check 3

個人作答 2 分鐘 → 與鄰座說明你的理由 → 全班表決 → 看解答
1AgNO3 與 NaCl 水溶液混合,沉澱是?
A NaNO3B AgClC 兩者都沉澱D 無沉澱
2下列哪一組混合後不會產生沉澱?
A BaCl2 + Na2SO4B KNO3 + NaClC Pb(NO3)2 + KID AgNO3 + K2CrO4
3莫爾法用 K2CrO4 當指示劑測氯離子。為什麼終點時才出現磚紅色,而不是一開始就出現?
解答:
1. B — 硝酸鹽全部可溶,所以 NaNO3 不會沉澱;AgCl 難溶。選 A 的同學溶解度規則背反了。最好用的兩條:硝酸鹽全溶、鹼金屬鹽全溶 —— 先用這兩條刪掉一半選項。
2. B — K+、Na+ 都是鹼金屬,NO3−、Cl− 交叉配對後仍全溶。A 生成 BaSO4、C 生成 PbI2、D 生成 Ag2CrO4,都是常見沉澱。固定動作:交叉配對後,對兩個新組合各查一次規則。
3. 因為 AgCl 比 Ag2CrO4 難溶得多 — 加入的 Ag+ 會優先與 Cl− 結合。只有等 Cl− 幾乎耗盡,多滴的那一滴 Ag+ 才輪得到鉻酸根 → 磚紅色出現 = 終點。這題的價值在於:指示劑本身也是一個沉澱反應,而且它能當指示劑的唯一理由,就是它比目標沉澱「更容易溶」。這條推理在 W16 講溶解度平衡時會再用一次。
PART 5.4

酸鹼反應

Acid–Base Reactions
Arrhenius 與 Brønsted-Lowry 定義・強酸強鹼・中和反應

Arrhenius 酸鹼定義 Arrhenius Definition

定義酸 (acid):溶於水解離出 H+(氫離子)的物質。
鹼 (base):溶於水解離出 OH−(氫氧根離子)的物質。
  • HCl → H+ + Cl−;NaOH → Na+ + OH−
  • H+ 在水中實際以水合氫離子 (hydronium ion) H3O+ 存在
  • 侷限:只適用於水溶液,也無法解釋 NH3 為何是鹼

Brønsted-Lowry 酸鹼定義(簡介) Brønsted-Lowry Definition

定義酸:質子 (H+) 的提供者 (proton donor);鹼:質子的接受者 (proton acceptor)。
NH3(aq) + H2O(l) ⇌ NH4+(aq) + OH−(aq)
  • NH3 接受質子 → 是鹼;H2O 提供質子 → 此處是酸
  • 範圍比 Arrhenius 更廣,不限水溶液;詳細內容於酸鹼平衡章節再深入

常見強酸與強鹼(必背) Common Strong Acids and Bases

化學式名稱
HCl / HBr / HI氫氯酸/氫溴酸/氫碘酸
HNO3硝酸
H2SO4硫酸

中和反應與鹽 Neutralization and Salts

定義中和反應 (neutralization):酸 + 鹼 → 鹽 (salt) + 水。
鹽 = 由酸的陰離子與鹼的陽離子組成的離子化合物。
HCl(aq) + NaOH(aq) → NaCl(aq) + H2O(l)
  • 強酸 + 強鹼的淨離子方程式皆為:H+(aq) + OH−(aq) → H2O(l)
  • 應用:制酸劑中和胃酸、處理酸性廢水

例題 6:中和反應方程式 Example 6

例題寫出醋酸 CH3COOH(弱酸)與 NaOH 水溶液反應的分子方程式與淨離子方程式。
解:
分子方程式:CH3COOH(aq) + NaOH(aq) → CH3COONa(aq) + H2O(l)
醋酸是弱電解質不拆;NaOH、CH3COONa 是強電解質要拆:
CH3COOH + Na+ + OH− → CH3COO− + Na+ + H2O
淨離子式:CH3COOH(aq) + OH−(aq) → CH3COO−(aq) + H2O(l)
(與強酸的 H+ + OH− → H2O 不同!)

酸鹼反應在食品分析:測蛋白質 Kjeldahl Method

問題營養標示的「蛋白質 8.0 g」怎麼來的?沒有人去秤蛋白質 —— 是量氮,再乘一個係數。
步驟做什麼反應
① 消化濃 H2SO4 + 觸媒,加熱有機氮 → NH4+
② 蒸餾加過量強鹼NH4+ + OH− → NH3↑ + H2O
③ 滴定用標準酸吸收並滴定酸鹼中和 → 回推 n(N)
粗蛋白 % = 氮 % × 6.25　(蛋白質平均含氮 16%,100/16 = 6.25;乳品用 6.38、小麥 5.70)
方法的漏洞它量的是總氮,不是蛋白質 —— 所以叫「粗蛋白」。三聚氰胺 C3H6N6 含氮高達 66.6%(蛋白質只有 16%),摻進去會讓數字暴增。2008 年毒奶粉事件鑽的正是這個化學漏洞。方法決定了你量到什麼。

PART 5.5

氧化還原反應

Oxidation–Reduction (Redox) Reactions
氧化數・氧化劑與還原劑・常見反應類型

氧化與還原 Oxidation and Reduction

定義氧化 (oxidation):失去電子,氧化數上升。
還原 (reduction):獲得電子,氧化數下降。兩者必同時發生。
Zn(s) + Cu2+(aq) → Zn2+(aq) + Cu(s)
  • Zn:0 → +2(失 2e−,被氧化);Cu2+:+2 → 0(得 2e−,被還原)
  • 英文口訣:LEO says GER(Lose Electrons = Oxidation;Gain Electrons = Reduction)

氧化數規則 Oxidation Number Rules

  1. 元素態(單質)氧化數 = 0(如 Fe、O2、P4)
  2. 單原子離子氧化數 = 其電荷(Na+ 為 +1、S2− 為 −2)
  3. F 恆為 −1;H 通常 +1(金屬氫化物中為 −1,如 NaH)
  4. O 通常 −2(過氧化物中 −1,如 H2O2;OF2 中 +2)
  5. 中性化合物中氧化數總和 = 0;多原子離子中總和 = 離子電荷
重點規則有優先順序:編號越前面越優先,衝突時以前者為準。

例題 7:指定氧化數 Example 7

例題求下列畫底線元素的氧化數:(a) KMnO4 中的 Mn  (b) Cr2O72− 中的 Cr  (c) NH3 中的 N  (d) NaH 中的 H
解:
(a) K = +1、O = −2:(+1) + Mn + 4(−2) = 0 → Mn = +7
(b) 2Cr + 7(−2) = −2 → 2Cr = +12 → Cr = +6
(c) H = +1:N + 3(+1) = 0 → N = −3
(d) Na = +1(第 1 族):+1 + H = 0 → H = −1(金屬氫化物特例)

氧化劑與還原劑 Oxidizing and Reducing Agents

氧化劑 oxidizing agent還原劑 reducing agent
自身變化被還原(氧化數下降)被氧化(氧化數上升)
電子流向獲得電子失去電子
作用使對方氧化使對方還原
常見例子O2、KMnO4、Cl2活性金屬(Zn、Na)、H2、C
注意「氧化劑自己被還原」— 名稱描述的是它對對方的作用,最容易搞反!

例題 8:判斷氧化還原 Example 8

例題Zn(s) + 2HCl(aq) → ZnCl2(aq) + H2(g)。判斷此反應是否為氧化還原反應;若是,指出氧化劑與還原劑。
解:標出氧化數:
Zn:0 → +2(上升,被氧化);H:+1 → 0(下降,被還原);Cl:−1 → −1(不變)
氧化數有變化 → 是氧化還原反應 ✓
還原劑 = 被氧化者 = Zn;氧化劑 = 含被還原元素者 = HCl
技巧判斷是否為氧化還原:看有無元素的氧化數改變。單質出現或消失,幾乎必是氧化還原。

反應類型:化合與分解 Combination & Decomposition

化合反應 A + B → AB

  • 2Mg(s) + O2(g) → 2MgO(s)
  • N2(g) + 3H2(g) → 2NH3(g)

分解反應 AB → A + B

  • CaCO3(s) → CaO(s) + CO2(g)
  • 2H2O2(aq) → 2H2O(l) + O2(g)
重點涉及單質的化合/分解反應必為氧化還原;CaCO3 分解則不是(各元素氧化數皆未變)。

單取代反應與活性序 Single Displacement & Activity Series

A + BX → AX + B  例:Zn(s) + CuSO4(aq) → ZnSO4(aq) + Cu(s)
定義活性序 (activity series):金屬依失電子傾向排列;活性大的金屬可取代活性小的金屬離子(或酸中的 H)。

K > Ca > Na > Mg > Al > Zn > Fe > Ni > Sn > Pb > (H) > Cu > Hg > Ag > Au

  • H 之前的金屬可與酸反應放出 H2;Cu、Hg、Ag、Au 不與鹽酸反應
  • Cu + ZnSO4 → 無反應(Cu 活性小於 Zn)
注意K、Ca、Na 遇水即反應(2Na + 2H2O → 2NaOH + H2),不可用於水溶液單取代 — 不會發生 2Na + CuSO4 → Na2SO4 + Cu。

燃燒反應 Combustion Reactions

定義燃燒 (combustion):物質與 O2 快速反應並放出大量熱與光,屬氧化還原反應。
  • 碳氫化合物完全燃燒:CxHy + O2 → CO2 + H2O
  • 例:C3H8(g) + 5O2(g) → 3CO2(g) + 4H2O(g)(液化石油氣)
  • 氧氣不足時不完全燃燒 → 產生 CO(有毒)或碳粒

例題 9:反應類型綜合判斷 Example 9

例題判斷下列反應的類型(可複選),並指出何者為氧化還原:
(a) 2Mg + O2 → 2MgO  (b) CaCO3 → CaO + CO2
(c) Fe + CuSO4 → FeSO4 + Cu  (d) AgNO3 + NaCl → AgCl↓ + NaNO3
解:
(a) 化合 + 燃燒 + 氧化還原(Mg 0→+2、O 0→−2)
(b) 分解;氧化數皆未變 → 非氧化還原
(c) 單取代 + 氧化還原(Fe 為還原劑、CuSO4 為氧化劑)
(d) 複分解(沉澱);非氧化還原

回到本週的錨點 Anchor Answered

第 5 週開場問的是:食譜有時要加小蘇打,有時要泡打粉,有時還要另外加檸檬汁或優格。為什麼?

用這一週的化學回答

  • 小蘇打受熱分解:2 NaHCO3 →(Δ) Na2CO3 + H2O + CO2 —— 產生的氣體是 CO2,它把麵糊撐開。
  • 但剩下的 Na2CO3 是鹼:帶鹼味,而且鹼性使麵粉裡的類黃酮呈黃色 → 這就是鹼味與黃斑的來源。
  • 所以要加酸(檸檬汁、優格、塔塔粉)把碳酸鈉中和掉,順便在室溫下就先放出一部分 CO2。
  • 泡打粉 = 小蘇打 + 固體酸 + 澱粉,比例已經配好,所以食譜用泡打粉時就不必再另外加酸。
這個情境幫你理解的化學是判斷一個反應,不能只看你要的產物,還要看剩下什麼。而這一週的三類反應還有另一個身分:沉澱→測食鹽、酸鹼→測蛋白質、氧化還原→測維生素 C 與油脂酸敗 —— 反應類型就是食品分析的三大滴定法。

本週重點總結 Summary

  • 平衡反應式:只調係數不改下標;化整數比;燃燒依 C → H → O
  • 離子方程式:可溶強電解質才拆;刪旁觀離子得淨離子式(查原子與電荷平衡)
  • 沉澱:交換配對 + 溶解度規則;都可溶則無反應
  • 酸鹼:強酸 6 種、強鹼為 1 族與 Ca/Sr/Ba 氫氧化物;強酸強鹼中和淨離子式 H+ + OH− → H2O
  • 氧化還原:氧化數上升 = 被氧化 = 還原劑;下降 = 被還原 = 氧化劑
