# 依數性質：先數粒子再計算

學習目標：能依粒子數計算凝固點下降，分清M、m與i的近似條件。

對象：食品營養系普通化學初學者；短句中文，越南語關鍵詞輔助

## 1. 粒子濃度，改變溶劑性質

在稀、近理想溶液模型中，依數性質主要取決於溶質粒子濃度。電解質可能解離成多個離子，所以要用范特荷夫因子修正。濃溶液不能保證沿用同一近似。

## 2. M和m，只差一字母卻不同

大寫莫耳濃度分母是公升溶液，小寫重量莫耳濃度分母是公斤溶劑。凝固點下降用小寫濃度；滲透壓近似式用大寫濃度，溫度必須用克耳文。

## 3. 0.100 m糖水降幾度

水的凝固點下降常數取一點八六度公斤每莫耳。零點一零零重量莫耳濃度葡萄糖，近理想且不解離，凝固點下降多少？

參考答案：下降0.186 °C；凝固點約−0.186 °C。

## 4. 答案：下降0.186度

一乘一點八六乘零點一，是零點一八六度。凝固點下降量是正值，新的凝固點則是零減下降量。不要把下降量的正號，直接當成新的凝固點。

## 5. 鹽類的i，不一定是理想整數

氯化鈉理想完全解離可給兩個離子，但實際離子交互作用會影響有效粒子數。本題若實測取一點九，就使用一點九，不擅自改成二。

## 6. 同樣0.100 m，誰降得更多

在理想解離模型下，比較葡萄糖、氯化鈉與氯化鈣，溶劑與濃度相同。哪一種凝固點下降最大？請先算解離後的粒子比例。

作答停頓：HTML 自動暫停；MP4 保留固定思考時間。

參考答案：CaCl₂；理想模型的有效粒子最多。

## 7. 答案：理想模型下氯化鈣最多

理想氯化鈣分成一個鈣離子與兩個氯離子，所以同樣重量莫耳濃度下，預測下降最大。冰淇淋的糖讓凍結溫度降低，但質地也受脂肪、空氣、冰晶大小與製程影響。
